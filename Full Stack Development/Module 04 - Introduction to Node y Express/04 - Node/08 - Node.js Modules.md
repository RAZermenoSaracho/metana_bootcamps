# Node.js Modules

![](https://resources.metana.co/public/33/5b/335bcab6689e8e57cb203a79ea66b97e7e3589b69db0c6725311786ba0196e21.png)

Think of Node.js like a Swiss Army knife for working with web servers and applications. Just like a Swiss Army knife has different tools for different tasks, Node.js has core modules, each designed to handle specific tasks in building web applications.

### Here are some of the essential core modules and what they do

- **File System (fs):** The fs module in Node.js helps you deal with files and folders on your computer. It lets you do things like read, write, delete files, and create or delete folders. It's like a toolbox for managing files in your Node.js programs.

- **HTTP (http):** The http module in Node.js allows your computer to communicate with other computers over the internet using a protocol called HTTP. It helps you create web servers that can listen for requests from web browsers and send back responses. Think of it as the foundation for building web applications or websites with Node.js.

- **Path (path):** The path module in Node.js is like a helper for working with file and folder paths. It helps you handle these paths in a consistent way, regardless of whether you're using Windows, macOS, or Linux. It can do things like make paths look the same on different systems, create paths from different parts, and extract information like file extensions or folder names.

- **Events:** The events module in Node.js is all about event-driven programming. It allows you to create and manage events in your programs. Events are like signals that can be sent when something happens. You can use events to tell your program to do certain tasks when specific conditions are met, or to notify when an action is completed. It's a way to make your programs respond to different situations.
