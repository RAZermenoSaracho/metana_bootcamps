# Clients and Server

In this tutorial you will be covering the following points :

- **Communication Process**:
  - Browser sends requests to the server when a user enters a website address.
  - Server decides what to send back as a response (HTML, images, CSS, JSON, etc.).
- **Domain Names and IP Addresses**:
  - IP addresses uniquely identify computers on the Internet.
  - Special computers (hosts) host websites, each with a unique IP address.
  - Domain names mask IP addresses for easier user access.
- **HTTP (Hypertext Transfer Protocol)**:
  - Facilitates communication between the browser and server.
  - Allows effective data exchange.
- **Node.js Server Creation**:
  - Node.js code manually creates the server on the backend.
  - Unlike languages like PHP, Node.js requires manual server creation.
- **Local Server Creation with Node.js**:
  - Use Node.js to create a server using the HTTP module.
  - Server listens for requests via a specified port and localhost.
- **Localhost and Port Numbers**:
  - Localhost refers to the user’s own computer, acting as a host.
  - Port numbers represent channels for software to communicate.
  - Common local development port is 3000.
- **Sending Requests and Server Response**:
  - A browser sends a GET request when a user types a web address.
  - Node.js server logs requests and responds through the HTTP module.
- **Running Node.js Server**:
  - Execute the Node.js server file (e.g., `node server.js`).
  - Server actively listens for requests on the specified port.
- **Interaction with Console**:
  - Server-side logs appear in the terminal/console, not the browser console.
- **Terminating Server Process**:
  - Use `Ctrl + C` to cancel out of the process and stop the server.
- **Sending Responses to the Browser**:
  - Response to the browser is managed through the response object.
  - Detailed exploration of response handling in the next lesson.
