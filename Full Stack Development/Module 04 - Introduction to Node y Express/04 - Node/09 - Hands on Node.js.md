# Hands on Node.js

We recommend you to follow along the tutorial below, in this video you will be learning about the basic stuff

- Basic Node.js operations on a computer, such as running a JavaScript file through Node using a terminal, demonstrating how Node can execute JavaScript outside of a browser environment.
- Key differences between browser JavaScript and Node.js are highlighted, such as the global object (`window` in browsers vs. `global` in Node), showcasing Node's unique features and syntax.
- Node.js modules and the file system, including how to import and export modules, and how to use Node's core modules (e.g., `os` for operating system information, `fs` for file system operations) for enhanced functionality.
- Introduction to asynchronous programming in Node.js, demonstrating file reading and writing, directory manipulation, and the basics of streams and buffers for efficient data handling.
