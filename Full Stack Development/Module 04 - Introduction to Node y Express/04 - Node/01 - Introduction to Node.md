# Introduction to Node

### What is Node.js ?

![](https://resources.metana.co/public/fd/2e/fd2ee5e53f37273d196bfe3c061f79de8ae4332f5d492df4cc38a85850920afd.png)

Node.js is like a super tool that lets you use JavaScript, the language usually for making websites fun and interactive, to also write code that works on servers, not just in browsers. This is cool because it means you can use JavaScript to do things before a webpage even gets to your computer or phone.

Imagine JavaScript as a handy tool that used to work only in your web browser's toolbox. Now, with Node.js, this tool can also work outside the browser, like on servers where websites live before you see them. It uses a smart engine from Google Chrome to make this happen, turning JavaScript into super fast code that computers love.

Node.js is special because it can do many things at once without getting stuck. It's like being able to cook dinner, answer the phone, and do laundry all at the same time without burning the food. This makes it awesome for apps where lots of people need to talk to each other in real-time, like in chat apps.

### The Birth and Evolution of Node.js

![](https://resources.metana.co/public/11/88/11881cdc7c75e0667354ca2af065d740c14ea6c6ef97065c70b8bcc17119125d.png)

Node.js was made by Ryan Dahl in 2009 because he was tired of how old web servers couldn't handle lots of users at the same time. He wanted something better, so he created Node.js to let people use JavaScript for websites and servers, making everything run smoothly, especially for apps and websites that need to update a lot of info quickly. It got popular fast because it worked so well.

To help it grow, a special group called the Node.js Foundation was set up in 2015, and in 2019, it joined with another group to keep supporting Node.js. Now, Node.js is super important for making websites because it's fast, can handle a lot of users, and has a big group of people making it even better. Big companies love it, too.
