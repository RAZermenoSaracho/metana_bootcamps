# What is Backend in Web Applications ?

![](https://resources.metana.co/public/c9/bd/c9bd9a58e571ccb93f162885dd2078c7e70486c794c1240100ee76b404f1f03c.png)

The "backend" refers to the part of a web application that you don't directly see or interact with as a user. It's where the application's logic, data processing, and storage happen. This includes things like handling user authentication, retrieving data from a database, and performing calculations.

![](https://resources.metana.co/public/e3/fa/e3fa618495bee9328c86b73e3e32bde264281a27d8b9b70bf7ba81d8b1c07546.png)

Think of a web application was a car, the frontend would be what you see and interact with (like the steering wheel and dashboard), while the backend would be the engine and other components under the hood that make everything work together.
