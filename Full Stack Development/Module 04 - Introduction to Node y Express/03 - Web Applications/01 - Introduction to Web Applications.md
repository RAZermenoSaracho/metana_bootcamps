# Introduction to Web Applications

### Web applications vs Web Pages

![](https://resources.metana.co/public/1f/66/1f666401b07f9b5de1512e1e37d3e36d502f3b5493c45e73d2cf6f8ce599d333.png)

**What are Web Pages ?**

These are like individual pages you see on the internet, like a single document or a part of a website. They are made using languages like HTML, CSS, and JavaScript.

**What are Web Applications ?**

These are more like interactive software programs that you use through a web browser. They can do things like take input from users, process data, and give personalized responses. Examples include online shopping sites, social media platforms, and email services.
