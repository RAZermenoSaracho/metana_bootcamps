# Setting Up Express.js

### So what is Express.js ?

Express.js is like a helper for people who make websites using Node.js, which is a way to write server-side code using JavaScript. Think of Express.js as a set of tools that makes it easier and faster to build web applications and websites. It helps with handling things like routes (which help your website know what to do when someone visits a certain page), and it can manage sending the right files to the people visiting your site, like your webpage, pictures, or data.
