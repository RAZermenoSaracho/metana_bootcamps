# Module 04 : Learning Outcomes

By the end of this module, students will be able to:

- Introduction to Node.js and Express.js.
- Set up and manage Node.js projects and dependencies.
- Implement middleware and routing in Express.js applications.
- Understand what is a template engine and how to work with it.

### Unit 17: Introduction to Web Applications

**Learning Outcomes**

- Define the role of the backend in web applications.
- Identify various backend frameworks and their purposes.

### Unit 18: Introduction to Node.js

**Learning Outcomes**

- Install and configure Node.js on their development environment.
- Describe the architecture of Node.js.
- Differentiate between browser and Node.js environments.
- Utilize Node.js modules to organize code.
- Develop and run Node.js applications from the command line.
- Explain the concepts of clients and servers, and handle HTTP requests and responses.
- Use NPM to manage packages and dependencies in Node.js projects.

### Unit 19: Setting Up Express.js

**Learning Outcomes**

- Set up Express.js in a Node.js project.
- Handle dynamic data in Express.js applications.
- Serve web applications using Express.js.
- Structure REST APIs and write handler functions for web endpoints.

### Unit 20 : Templating Engines - Handlebars, Mustache, and EJS

**Learning Outcomes**

- Understand the purpose of templating engines in web development.
- Learn the syntax and features of Handlebars, Mustache, and EJS.
- Build simple projects using each templating engine.

### Unit 21: Fundamentals of Middleware

**Learning Outcomes**

- Understand the concept and purpose of middleware in Express.js.
- Implement middleware for routing, logging, and error handling.
- Add logger middleware to Express.js applications.
- Create dynamic page templates using Handlebars.

### Unit 22: What is NoSQL ?

**Learning Outcomes**

- Set up and configure MongoDB for backend data storage.
- Perform CRUD operations with MongoDB in a Node.js environment.
- Integrate MongoDB with Express.js applications to store and retrieve data.

### Unit 23: Understanding REST API

**Learning Outcomes**

- Understand what is REST APIs.
- Grasp the concept and structuring of REST APIs.

### Unit 24: Wrapping Up with Node.js

**Learning Outcomes**

- Organize and structure a Node.js project effectively.
- Implement and manage project dependencies and versioning.
- Set up linting and formatting tools in their IDE to maintain code quality.

### Assignment: Deploy a simple Node website with Express and Handlebars

In this assignment, you'll dive into the Handlebars templating engine, learning how to create and render dynamic templates using its syntax. You'll set up a Node.js project with Express.js to serve Handlebars templates, implement helpers for custom logic, use partials for reusable components, and apply block expressions for control flow. By working through practical tasks, you'll gain hands-on experience with Handlebars, understanding its strengths and how to leverage its features to build dynamic web applications.

### Assignment Outcomes

- Understand and apply Handlebars syntax for dynamic templating.
- Set up a Node.js project with Express.js to serve Handlebars templates.
- Implement and utilize helpers for custom logic within templates.
- Create and include partial templates for reusability.
- Apply HTML escaping and unescaping techniques.
- Build dynamic web applications using Handlebars.
