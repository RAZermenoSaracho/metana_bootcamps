# Fundamentals of Middleware

### What is a Middleware ?

![](https://resources.metana.co/public/13/ae/13ae44d60c27244a68fd3f6270c349748436f996d0d9b7083550838b1b13bf52.png)

Middleware is like a bridge between the incoming request and the server's response in web applications. It's a piece of code that sits in the middle of these two components. Think of middleware as a function that gets called for every request your server receives before sending a response back.
