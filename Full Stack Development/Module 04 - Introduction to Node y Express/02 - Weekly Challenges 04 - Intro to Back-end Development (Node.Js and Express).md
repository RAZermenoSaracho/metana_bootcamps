# Weekly Challenges 04 : Intro to Back-end Development (Node.Js and Express)

In this module, we delve deeper into the concept of web applications and explore how they function by building a server using Node.js and Express. You will learn how the front end, back end, and database work together to power modern web applications. you’ll have a practical understanding of servers, the role of Node.js in running JavaScript outside of the browser, and how to create a basic server with Express. This module is designed to help you gain hands-on experience with backend development and full-stack web applications.

---

## Weekly Challenges

Here’s the latest set of weekly challenges for you to dive into! Remember, there are no strict rules—feel free to get creative and make them your own. Be sure to showcase your unique solutions during this week’s Office Hours session. Good luck, and happy coding!

**Challenge 1: Hello, Server!**

Create your very own Express server that says “Hello, world!” when you visit it in the browser. Start by setting up your server and getting it to display this simple message. Once that works, change the message to something more creative or funny. How about “Hello, coding wizard!”?

---

**Challenge 2: Personal Greeting Machine**

Build a server that greets visitors by name! Set up a route that takes a name as input (through the URL) and returns a personalized message like, “Hello, [Your Name]! Welcome to the server!” Try testing it with different names and make the greetings as fun as you want.

---

**Challenge 3: Fortune Teller**

Turn your server into a digital fortune teller! Create a route that returns a random fun fortune or life advice every time someone visits. Example fortunes could include “You will write amazing code today!” or “An exciting bug fix is in your near future!” Let your imagination run wild!
