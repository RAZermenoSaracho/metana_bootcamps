# Module 08 : Learning Outcomes

[YouTube video player](https://www.youtube.com/watch?v=VsqnfU7wHBU)

By the end of this module, students will be able to:

- Understand the basic concepts of frontend development and the limitations of using only HTML for interactive applications.
- Learn the core features and benefits of using React for building dynamic web applications.
- Differentiate between client-side rendering and server-side rendering, and understand the pros and cons of each approach.
- Gain proficiency in creating and managing React components, including functional and class components.
- Understand and implement React Router for handling navigation in single-page applications (SPAs).
- Learn the concepts of props and state in React, including state management and lifecycle methods.
- Master JSX syntax and the use of "children" in React components.
- Set up, initialize, and structure a React project using create-react-app.
- Understand and use React hooks for state management, effects, data storage, and context.
- Learn how to use refs for storing values that do not trigger re-renders.
- Understand the process and benefits of bundling in web development, including tree-shaking and minimizing code.
- Get introduced to Redux and its role in state management within React applications.
- Develop a monolithic application combining both frontend and backend in a single project structure.

### Unit 45: Introduction to Frontend Development

**Learning Outcomes**

- Understand the concept of frontend development.
- Learn why using only HTML for web applications is insufficient.

### Unit 46: What is React and Why Use React

**Learning Outcomes**

- Understand the basics of React and its advantages over traditional HTML and JavaScript.
- Explore alternative frameworks like Vue.js, Angular, and Svelte.

### Unit 47: Features of React

**Learning Outcomes**

- Learn about React's interactivity, client-side rendering, and capabilities for building SPAs.
- Understand the dynamic nature of React and its ability to handle complex logic in HTML markup.

### Unit 48: Understanding the Inner Workings of React

**Learning Outcomes**

- Learn how React works, including client-side rendering and JSX compilation.

### Unit 49: Components in React

**Learning Outcomes**

- Understand what components are, their purposes, and the difference between functional and class components.

### Unit 50: Mounting React Components

**Learning Outcomes**

- Learn how React mounts components onto the DOM and manages their updates.

### Unit 51: Server-Side Rendering vs Client-Side Rendering

**Learning Outcomes**

- Compare server-side rendering (SSR) and client-side rendering (CSR), understanding their benefits and drawbacks.

### Unit 52: Intro to Single Page Applications (SPAs)

**Learning Outcomes**

- Understand the concept of SPAs and how React Router helps manage navigation in SPAs.

### Unit 53: Props vs. State

**Learning Outcomes**

- Learn how components receive data via props and manage internal data with state.
- Understand the differences between props and state and their roles in React component lifecycle.

### Unit 54: JSX Syntax

**Learning Outcomes**

- Get familiar with JSX syntax and its compilation process.

### Unit 55: Children in React

**Learning Outcomes**

- Learn how to pass "children" to React components for nested rendering.

### Unit 56: React Router

**Learning Outcomes**

- Understand React Router and its use in managing routes and navigation in a SPA.

### Unit 57: Initializing a React Project

**Learning Outcomes**

- Set up and initialize a new React project using create-react-app.

### Unit 58: Structuring a React Project

**Learning Outcomes**

- Learn best practices for structuring a React project.

### Unit 59: Dynamic Data Handling in React

**Learning Outcomes**

- Understand how to handle dynamic data in React, including passing data as props and handling asynchronous data fetching.

### Unit 60: Exploring React Hooks

**Learning Outcomes**

- Learn about different React hooks:
  - **State Hooks**: useState
  - **Effect Hooks**: useEffect, useAsyncEffect
  - **Data Storage Hooks**: useRef, useMemo
  - **Context Hooks**: useContext

### Unit 61: Refs in React

**Learning Outcomes**

- Understand what refs are and their use cases in React.

### Unit 62: Bundling in Web Development

**Learning Outcomes**

- Learn the importance of bundling, common bundlers, and techniques like tree-shaking.

### Unit 63: React Redux

**Learning Outcomes**

- Get introduced to Redux for state management and understand its role in complex React applications.
