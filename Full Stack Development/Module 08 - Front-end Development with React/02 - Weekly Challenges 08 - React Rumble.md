# Weekly Challenges 08 : React Rumble

Welcome to **Weekly Challenges 08: React Rumble!** This week’s challenges are all about building dynamic and interactive React applications in a fun, creative way. These challenges will let you flex your skills with React components, hooks, and simple state management. **Pick at least one challenge this week** to dive in and bring your ideas to life!

---

### Challenge 1: **“React Soundboard”**

**Description:**

Create a soundboard application using React. The soundboard should display buttons that, when clicked, play different sounds (e.g., animal noises, musical notes, funny sound effects). Use state to manage which sound is playing, and add visual feedback (like changing button colors) to indicate when a sound is active. You May use this web-page as a resource: <https://www.myinstants.com/en/categories/memes/>

- **Extensions:** Add a volume slider to control the sound volume or create categories of sounds users can switch between.
- **Skills Covered:** React state management, handling events, basic UI updates.

---

### Challenge 2: **“Click Counter Game”**

**Description:**

Build a simple React application that displays a button and a counter. When the button is clicked, the counter increases. Add a second button that resets the counter. Make the game more engaging by adding a timer that counts down, and challenge the user to get the highest possible score before time runs out!

- **Extensions:** Add different button types that give bonuses (e.g., double points for a limited time) or implement a “leaderboard” to track high scores.
- **Skills Covered:** React state, event handling, simple game logic.

---

### Challenge 3: **“Random Color Generator”**

**Description:**

Create a React app with a button that, when clicked, changes the background color of a div to a randomly generated color. Display the hex code of the color so users can see what was generated. Add buttons to “copy” the hex code or “lock” a color to prevent it from changing on the next button click.

- **Extensions:** Allow users to save their favorite colors in a list or implement a feature to generate matching color palettes.
- **Skills Covered:** React state, event handling, dynamic styling.
