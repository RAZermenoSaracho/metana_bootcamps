# Overview of the To-Do Application

Welcome to your first project in this bootcamp! This bootcamp is designed to be heavily assignment-based, giving you hands-on experience with building real projects that will form part of your portfolio. This portfolio is an excellent tool for showcasing your skills and gaining real-world experience, which is invaluable when you’re looking to get hired.

Let us introduce the first project you’ll work on:

**A To-Do App with Mood and Weather-Based Task Suggestions Powered by a Weather API**

![](https://resources.metana.co/public/a2/0e/a20ebc5db2a16cf527d00e72e20b7c239e1dd96d29e6c3cab67bd495653c2c21.png)

Sounds intriguing, right? While it may seem complex at first, don’t worry, we don’t expect you to build it all in one go.

This project is broken down into manageable pieces, and you’ll construct it step by step over the first four modules of the bootcamp. Think of it as assembling a Lego Technic Kit: you’ll build smaller components and then piece them together to complete the app.

---

## Module Breakdown

### Week 01: Setting up Your Git and GitHub Repo

In the first week, you’ll learn how to initialize a Git repository, set up your GitHub repo, and understand the importance of version control. These skills are foundational for every developer.

### Week 02: Building a Static Front End

Here, you’ll create the user interface (UI) of the app using HTML and CSS. This will help you visualize the structure and design before adding any functionality.

### Week 03: Adding Logic and Functionality

You’ll start coding the app’s logic using JavaScript. This includes creating, editing, deleting, and completing tasks within the app. You’ll also explore how to make the app dynamic and interactive.

### Week 04: Creating the Backend Server + Working with APIs

In the final step, you’ll set up a backend server and integrate APIs, like the weather API, to fetch live weather data. This is where your app becomes fully functional.

### Key Features to Explore

To fully understand the app’s functionality, try out these features on the hosted version:

- **Create a Task:** Add a task to your to-do list.
- **Complete a Task:** Mark a task as completed.
- **Delete a Task:** Remove tasks from the list.
- **Edit a Task:** Modify the details of a task.
- **Change Mood:** Update your mood using the mood selector.
- **Check Weather:** View weather-based suggestions and updates.
- **Login:** Access and manage your tasks securely.

## Repository Structure Overview

As you begin to work on this project, understanding the standard repository structure is essential. Here’s a breakdown of common folders you’ll encounter:

- **`src/`**: Contains the source code for your application, including JavaScript/TypeScript files, components, and styles.
- **`public/`**: Includes static assets like images, icons, and the `index.html` file that is served to the browser.
- **`docs/`**: Houses documentation files, such as a README, contribution guidelines, and detailed project instructions.

Maintaining a clear structure will help you and others navigate your project efficiently.
