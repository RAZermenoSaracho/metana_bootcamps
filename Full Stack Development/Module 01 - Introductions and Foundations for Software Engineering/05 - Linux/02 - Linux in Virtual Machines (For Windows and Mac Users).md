# Linux in Virtual Machines (For Windows and Mac Users)

For Linux we recommend following along in the next unit with your terminal.

What is really a virtual machine ? Virtual Machine (VM) is like a computer within your computer. It’s a software implementation that emulates a physical computer’s hardware and allows you to run an operating system and applications in an isolated environment.

**So what is meant by setting up linux in a VM ?**

This means you install Linux inside a virtual machine. This process includes choosing a virtualization software ( like Virtual Box that we recommend to use ), creating a new virtual machine, and then installing Linux on it, just as you would on a physical computer. The key advantage here is that you can run Linux alongside your current operating system (like Windows or macOS) without affecting your primary system. You can easily switch between the host OS and the Linux VM.
