# Module 01 : Learning Outcomes

By the end of this module, students will be able to:

- Apply foundational concepts in software engineering to solve problems effectively.
- Utilize Linux/Unix environments and basic commands proficiently.
- Employ integrated development environments (IDEs) to streamline the coding process.
- Implement version control using Git and GitHub for collaborative software development.

### Unit 02: The Software Development Life Cycle

**Learning Outcomes**

- You will be able to identify and explain the key phases of the Software Development Life Cycle and their purpose in software development.
- You will gain the ability to compare different SDLC models (e.g., Waterfall, Agile) and determine when to apply each model based on project requirements and constraints.

### Unit 03: Algorithms and Problem Solving

**Learning Outcomes**

- Construct flow diagrams to visually represent the logic and flow of algorithms.
- Write pseudocode to outline algorithmic solutions in a structured and language-agnostic format.

### Unit 04: Introduction to Linux

**Learning Outcomes**

- Navigate the Linux/Unix operating system and execute basic commands.
- Start a virtual machine (VM) and install a Linux distribution.
- Manage software packages using Linux package management tools.
- Define shell scripts, explain their purpose, and write basic shell scripts to automate tasks.

### Unit 05: Integrated Development Environment (IDE)

**Learning Outcomes**

- Set up and configure an IDE for software development.
- Utilize IDE features to write, debug, and test code efficiently.

### Unit 06: Git and GitHub

**Learning Outcomes**

- Explain the principles of version control and its importance in software development.
- Use Git to track changes in source code and collaborate with others.
- Execute basic Git commands to manage repositories.
- Create and manage repositories on GitHub.
- Work with remotes and upstream repositories for collaborative development.
- Use branches to manage different versions of a project.
- Write and format Markdown files for project documentation on GitHub.
- Configure GitHub for the Metana Full Stack development environment.
