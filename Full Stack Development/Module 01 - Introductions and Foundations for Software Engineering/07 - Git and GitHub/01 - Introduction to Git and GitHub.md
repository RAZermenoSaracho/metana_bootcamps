# Introduction to Git and GitHub

Simply GitHub is the most popular platform among developers and it uses Git, which you learned in the previous topic. Here is an official definition :

GitHub is a web-based platform that provides hosting for software development and version control using Git. It offers a variety of collaboration and project management features, making it a central hub for developers to work together on software projects.

### Maintaining repositories are similar to community farming...

![](https://resources.metana.co/public/49/a5/49a536019c842a1648df0035b4c17555b86e2dc7b8e7240beb85d733d0400a2f.png)

**Garden (Local Repository):**

- The entire garden represents the repository. It's the collective space where different types of vegetables are grown, and changes to the vegetable varieties can be managed.

In Git, your local repository is where you create, modify, and manage your project. It's your personal workspace where you can experiment with different ideas.

**Vegetable Patches (Branches):**

- Each separate patch within the garden represents a branch in Git. For example, you might have a "Tomato Patch" branch, a "Carrot Patch" branch, and so on. Each branch allows you to work on different aspects of your project without affecting the others.

In Git, a branch is like a separate line of development. You can have different branches for features, bug fixes, or experiments. Each branch allows you to work on a specific aspect of your project without affecting the main codebase.

**Community Greenhouse (Origin/Remote Repository):**

- The community greenhouse represents the origin repository. It's a shared space where different gardeners (developers) contribute to the overall collection of vegetables (codebase).

The remote repository is a shared space where multiple developers collaborate on a project. It's a centralized location where everyone can access and contribute to the codebase.

****Expert Gardener's Garden** (Upstream):**

- There's an expert gardener in the community who has a stunning garden with well-established plants. This garden is the upstream repository.

The upstream repository is a remote repository that you forked your project from. It often represents a more authoritative or official source that you want to stay synchronized with.

**Forking** : In this scenario, involves creating a copy of the entire garden and taking it to your personal space.

Now that we have a basic understanding of the concept, let's take a deeper dive into the key topics of this unit to explore Git and GitHub more thoroughly.
