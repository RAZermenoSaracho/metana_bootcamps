**Now that you know what Git is let's install it in your computer. It's time you get used to downloading software needed by reading a documentation. [Click here](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)**

**How to check if you have the Git**

Step 1: Access the terminal.

Step 2 : Once the terminal loads , type the following command and press enter.

code

```
git
```

Step 3 : Now navigate to your desktop and create a folder as "trying out git".

code

```
mkdir "trying out git"
```

Step 4 : Now access that folder

code

```
cd "trying out git"
```

Step 5 : Now type **git init** to initialize your empty repository

code

```
git init
```
