# Basic Git Commands

Git commands are like magic spells that help you manage your project's history and changes. Let's dive into some of the essential ones,

1. **Initializing a New Repository** When you start a new project, you'll want to set up a Git repository to track its changes. Here's how you do it: `git init` This command initializes a new Git repository in your current directory, creating a hidden folder called `.git` where Git stores all its magic.
2. **Cloning a Repository** If you want to work on an existing project stored on a remote server (like GitHub), you can clone it to your local machine: `git clone <repository_url>` Replace `<repository_url>` with the URL of the repository you want to clone. This command creates a local copy of the repository on your computer, ready for you to start working on.
3. **Staging Changes** Before you commit changes to your repository, you need to stage them. Staging tells Git which changes you want to include in the next commit. You can stage specific files or all changes: `git add <file1> <file2> ...` or `git add .` The first command stages specific files, while the second command stages all changes in the current directory.
4. **Committing Changes** Once you've staged your changes, you're ready to commit them to your repository: `git commit -m "Your commit message"` Replace `"Your commit message"` with a brief description of the changes you're committing. This message helps you and others understand what the commit does.
5. **Checking the Status of Files** To see which files have been modified, staged, or untracked in your repository, you can use the status command: `git status` Git will then display a list of files and their current status, helping you keep track of what's going on in your project.
6. **Viewing Commit History** Git keeps a record of all the commits you've made in your repository. You can view this commit history to see what changes have been made over time: `git log` This command displays a list of commits, including their unique identifiers, authors, dates, and commit messages.

By mastering these basic Git commands, you'll have the power to track changes, collaborate with others, and keep your project's history organized and under control.
