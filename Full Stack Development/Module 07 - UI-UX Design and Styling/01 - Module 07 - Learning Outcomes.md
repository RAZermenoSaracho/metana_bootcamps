# Module 07 : Learning Outcomes

[YouTube video player](https://www.youtube.com/watch?v=-o3fd91IDsA)

By the end of this module, students will be able to:

- Understand wireframing: purpose and basic concepts.
- Practice wireframe designing basic components.
- Learn how to build a web design mockup with Figma.
- Learn how to do basic styling with TailwindCSS.
- Know how to use the web to find inspiration and resources for a new web design, using HTML/CSS template sites and looking at other websites’ designs.

### Unit 37: Introduction to Wireframing, UI Kits, and Responsive Design

**Learning Outcomes**

- Understand what wireframing is.
- Learn key design considerations.
- Gain knowledge of UI kits.
- Get a brief introduction to the design process.

### Unit 38: Introduction to Frontend Frameworks

**Learning Outcomes**

- Understand the basics of Bootstrap.
- Understand the basics of TailwindCSS.

### Unit 39: Finding Inspiration for Design

**Learning Outcomes**

- Understand why to use sources for web design.
- Discover resources for design inspiration.
- Learn to use existing designs as guidelines for wireframing.

### Unit 40: Building Wireframes & Mockups with Figma

**Learning Outcomes**

- Explore example resources for wireframing.
- Learn to create wireframes with Figma.
- Understand wireframing basics (Wireframing 101).

### Unit 41: Mobile/Responsive Design Basics

**Learning Outcomes**

- Learn different approaches to responsive design.
- Summarize mobile responsive design principles.

### Unit 42: Adding Custom Fonts

**Learning Outcomes**

- Explore alternatives to Google Fonts for custom fonts.

### Unit 43: Adding Icons

**Learning Outcomes**

- Learn to add icons to enhance design.

### Unit 44: Putting It All Together

**Learning Outcomes**

- Integrate all learned concepts to complete a cohesive UI/UX design.

### Learning Outcomes for Module 7 Assignment

- **Project Initialization**: Set up a Node.js project and install Express.
- **Express Server Setup**: Create and configure an Express server.
- **Serving Static Files**: Serve static files using Express.
- **Error Handling**: Implement custom 404 error handling.
- **Tailwind CSS Integration**: Install and use Tailwind CSS for styling.
- **Styling with Tailwind CSS**: Style a website based on a Figma prototype.
- **Figma for UI Design**: Design a portfolio layout in Figma.
- **Interactive Prototyping**: Add interactivity to Figma wireframes.
- **Sharing Prototypes**: Generate and share interactive prototypes.
