# Module 11 : Learning Outcomes

[YouTube video player](https://www.youtube.com/watch?v=fRqA4SCiHa4)

By the end of this module, students will be able to:

- Understand and apply the concepts of deploying applications and cloud platforms.
- Comprehend the principles and practices of DevOps.
- Distinguish between various deployment environments and their purposes.
- Explain key terms related to hosting and deployment.
- Identify and utilize different hosting environments.
- Implement containerization for application deployment.
- Explore various deployment options including PaaS, VPS, and serverless functions.
- Manage database hosting options.
- Handle environment variables and application secrets securely.
- Configure webserver software and reverse proxies.
- Obtain and implement SSL certificates for secure connections.
- Deploy applications to different platforms through practical examples.

### Unit 107: Introduction to Deploying and Cloud Platforms

**Learning Outcomes**

- Understand the basics of deploying applications.
- Identify different cloud platforms and their uses.

### Unit 108: Introduction to DevOps

**Learning Outcomes**

- Comprehend the principles of DevOps.
- Recognize the benefits of implementing DevOps practices.

### Unit 109: Deployment Environments

**Learning Outcomes**

- Differentiate between development, testing, staging, and production environments.
- Understand security concerns in deployment environments.
- Determine the necessity of different deployment environments.

### Unit 110: Understanding Key Terms in Hosting and Deployment

**Learning Outcomes**

- Define key terms related to hosting and deployment.
- Explain the significance of these terms in practical scenarios.

### Unit 111: Hosting Environment

**Learning Outcomes**

- Identify different types of hosting environments.
- Understand the benefits and limitations of various hosting options.

### Unit 112: Containerization Platforms

**Learning Outcomes**

- Comprehend the concept of containerization.
- Utilize popular containerization platforms for deployment.

### Unit 113: Deployment Options

**Learning Outcomes**

- Explore different deployment options.
- Evaluate the suitability of each option for various applications.

### Unit 114: Deploying to PaaS

**Learning Outcomes**

- Understand the process of deploying applications to PaaS.
- Implement deployments using PaaS platforms like Vercel or Heroku.

### Unit 115: Deploying to VPS

**Learning Outcomes**

- Comprehend the steps to deploy applications to a VPS.
- Execute deployments on VPS platforms such as AWS.

### Unit 116: Deploying Apps as Serverless Functions

**Learning Outcomes**

- Understand serverless computing and its benefits.
- Deploy applications as serverless functions.

### Unit 117: Database Hosting

**Learning Outcomes**

- Differentiate between databases as a service and self-hosted databases.
- Choose the appropriate database hosting option for different scenarios.

### Unit 118: Environment Variables and Application Secrets

**Learning Outcomes**

- Manage environment variables and application secrets securely.
- Add environment variables in various platforms like Heroku, Vercel, and AWS VPS.

### Unit 119: Webserver Software and Reverse Proxies

**Learning Outcomes**

- Configure webserver software.
- Set up and manage reverse proxies.

### Unit 120: Domain Names and Secure Connections (SSL)

**Learning Outcomes**

- Understand the importance of SSL certificates.
- Obtain and implement SSL certificates for secure connections.
- Generate SSL certificates using Certbot and LetsEncrypt with Nginx.

### Unit 121: Example Case 1: Deploying to PaaS (Vercel or Heroku)

**Learning Outcomes**

- Apply the knowledge of PaaS deployment in a practical example.
- Deploy an application to Vercel or Heroku.

### Unit 122: Example Case 2: Deploying to VPS (AWS)

**Learning Outcomes**

- Implement VPS deployment techniques in a real-world scenario.
- Deploy an application to an AWS VPS.

### Unit 123: Advanced Topics

**Learning Outcomes**

- Explore advanced topics in deploying and cloud platforms.
- Apply advanced techniques in deployment scenarios.
