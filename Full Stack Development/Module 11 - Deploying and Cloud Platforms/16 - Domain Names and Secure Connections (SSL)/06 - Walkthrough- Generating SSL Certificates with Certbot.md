# Walkthrough: Generating SSL Certificates with Certbot

This is an example of setting up Certbot to generate certificates, using the command line tool.

- This is the basic process you’d use to generate certificates for a web application on a VPS.
- After creating your certificates, you need to let your webserver software (like Nginx or Apache) know where the certificates are.
- This tutorial won’t cover that — it’s only generating the certificates, but doesn’t cover how to register them.
- There are additional command-line options which will automatically configure our certificates with our webserver software (Nginx or Apache). We’ll include these in a following video.
