# SSL Certificates with LetsEncrypt and Nginx

- After generating certificates with Certbot, inform your web server software about their location.
- This is achieved through configuration files specific to your web server, such as Nginx or Apache.
- Our recommended VPS setup utilizes Nginx as a reverse proxy, while Apache is also commonly used.
