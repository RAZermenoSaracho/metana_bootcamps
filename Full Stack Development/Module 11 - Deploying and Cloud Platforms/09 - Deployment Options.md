# Deployment Options

Our three major deployment options are:

1. **Deploying to PaaS (Platform as a Service)**
   - PaaS provides a platform for developing, running, and managing applications without dealing with infrastructure management.
   - Typically offers "One-click deploy" solutions where you link your codebase to the service and click Deploy.
   - Examples include Heroku, Vercel, and Google App Engine.
2. **Deploying to VPS (Virtual Private Server)**
   - VPS offers virtualized computing resources over the internet, including servers, storage, and networking.
   - Users have more control and flexibility compared to PaaS but require sysadmin knowledge.
   - Examples include Amazon Web Services (AWS) EC2 and DigitalOcean Droplets.
3. **Deploying Serverless Functions** **(Function as a Service)**
   - Serverless functions are one-off functions that fire in response to events.
   - Developers upload code for the function, which runs independently of any underlying infrastructure.
   - Examples include AWS Lambda and Google Cloud Functions.

*Additional options include deploying as a **static site** using a CDN — this will be covered later.*
