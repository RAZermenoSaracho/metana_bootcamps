# Production Environment

- This is your final app, in a live environment accessible to the public and end-users.
- Requires stability, reliability, and performance optimization to ensure a seamless user experience.
- Production environment includes your production database.
- Ensure you’re using production access tokens for all 3rd party APIs.

> The production environment refers to where the software or products have been made live for use of the intended users. Once something is in the production environment, any and all bugs need to have already been fixed and the product or update must work perfectly.
