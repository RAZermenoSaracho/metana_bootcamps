# Development Environment

- Environment by developers for coding and initial testing.
- This is you and your machine, including IDE, testing tools, and any local development databases.

> A development environment in software and web development is a workspace for developers to make changes without breaking anything in a live environment.
>
>
>
> The development environment is often seen as a developer's “everything-goes” workspace.
