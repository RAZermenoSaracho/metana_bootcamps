# Adding Environment Variables to an AWS VPS Instance

**Manual Setup on VPS**

- With a VPS instance, you don’t need to set environment variables manually through a control panel.
- Since we have control of the server, and access to the file system, you can directly create your .env files when you copy and set up your application.
- Put your .env file in the normal location, and ensure that the values are correct (production environment / staging)
