# Local Storage, Session Storage and Browser Cache

### What is the Purpose ?

**Local Storage**: Local storage is a feature in web browsers that allows websites to store small amounts of data locally on your computer. This data is meant to be persistent, meaning it stays there even after you close the browser or turn off your computer. It's primarily used to save information that a website might need later, like user preferences or settings.

**Session Storage:** Session storage is similar to local storage, but with a key difference: the data stored in session storage is only available for the duration of the page session. This means that once you close the browser tab or window, the data is cleared. Session storage is useful for storing temporary data that a website needs only for a single session, such as form inputs or temporary state information.

**Browser Cache**: The browser cache, on the other hand, is a temporary storage area used to speed up web browsing. When you visit a website, some of its resources like images, stylesheets, and scripts are stored in the cache. If you revisit the same website, the browser can load these resources from the cache instead of downloading them again, making your web browsing faster.
