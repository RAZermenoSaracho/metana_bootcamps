# What is Exception Handling

![](https://resources.metana.co/public/cc/31/cc3199f38c74f6f70107cf34e12176f134b1c3eb211ed6edc6457e9ad73261b7.png)

When we write code, sometimes things can go wrong. For example, we might try to divide a number by zero, read a file that doesn't exist, or access a website that's down. These unexpected problems are called "exceptions."

**What is an Exception?**

An exception is like a red flag that says, "Hey, something went wrong!" It's a way for our program to recognize and deal with errors gracefully, instead of crashing or showing a confusing message to the user.

**What Happens if Our Code Generates an Error?**

If our code generates an error, and we haven't prepared for it, the program can crash. Imagine if you're driving a car, and suddenly a tire goes flat. Without a spare tire, you'd be stuck. In programming, exceptions are like having a spare tire – they help us handle errors and keep our program running smoothly.

### What is Try ?

Try" is like attempting a risky task in your code, such as dividing a number by zero or opening a file. You put the potentially problematic code inside a "try" block. Think of it as taking a chance or trying to do something that might work.

### What is Catch ?

"Catch" is like having a backup plan in case things go wrong inside the "try" block. If an error or problem occurs while executing the code in the "try" block, the program jumps to the "catch" block. In the "catch" block, you can specify what action to take when an error happens. It's like saying, "If something goes wrong, do this instead." Common actions in the "catch" block include displaying an error message to the user, logging the error for debugging, or taking corrective measures.
