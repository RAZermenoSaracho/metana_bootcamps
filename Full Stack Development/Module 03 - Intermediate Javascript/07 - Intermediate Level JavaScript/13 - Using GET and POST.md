# Using GET and POST

### What is GET ?

The GET method is like asking for information from a server. It's a safe way to get data without changing anything on the server.

### What is POST ?

The POST method is used to send data to the server and make a new record. It's like adding a new item to a list, and the server gives it a special number (ID) to keep track of it. In simple terms, POST is used to create new data entries.
