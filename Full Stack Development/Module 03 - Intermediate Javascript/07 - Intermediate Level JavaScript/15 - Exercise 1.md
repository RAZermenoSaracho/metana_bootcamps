# Exercise 1

### **Objective**

1. Create an interactive slider that allows users to select a value.
2. Save the selected value in a browser cookie using JavaScript.

![](https://resources.metana.co/public/a1/7d/a17d1d4416d17b80d1c242def47af68e5355abcd0a11310e2c1e448ca8f3b51f.png)

### **Specifications**

1. **UI Design**:
   - Create a slider that resembles the above design.
2. **Behavior**:
   - When the slider value changes, save the selected value into a cookies and add an expiry date for one day.
   - Upon page reload, retrieve the value from the cookie and set the slider's position.
3. **Advanced Challenge (Optional)**:
   - Add a **Reset Slider** button to clear the cookie and reset the slider to its default value.
