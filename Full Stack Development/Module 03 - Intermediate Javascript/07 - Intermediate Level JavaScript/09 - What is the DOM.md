# What is the DOM

![](https://resources.metana.co/public/41/79/41791664e940b5d5db8342aa4bd004380e747121ac696cbb4af5661e620d5e53.png)

The Document Object Model (DOM) is like a map of a webpage. Imagine you have a tree in your garden. This tree has a trunk, branches, leaves, and maybe some fruits. Similarly, a webpage is made up of various elements like text, images, buttons, and so on.

![](https://resources.metana.co/public/71/c5/71c506d0aa5ce8f90a282f1f505519cc2e0f6a867df648971dfb82b1e0947e8d.png)

In the DOM, the whole webpage is like the tree. Each part of the webpage, like a paragraph or an image, is like a branch or a leaf. These are called "nodes" in the DOM. The way these nodes are arranged resembles the structure of a tree, with branches leading to smaller branches and leaves.
