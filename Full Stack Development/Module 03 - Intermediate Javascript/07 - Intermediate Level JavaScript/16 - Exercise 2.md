# Exercise 2

### **Objective**

1. Create a button that, when clicked, opens a dialog box for the user to input task details (e.g., Task Name, Description).
2. After entering the task and clicking "Add Task," the task will be added dynamically to a list displayed on the page.

### **Specifications**

1. **UI Design**:
   - A clean and minimal interface with a button to open the dialog box.
   - A dialog box displayed in the center with input fields for task details (e.g., Task Name, Description).
   - A task list displayed above the button.
2. **Behavior**:
   - Clicking the **Add Task** button inside the dialog box adds the task to the HTML list dynamically.
   - Implement a **Cancel** button to close the dialog without adding a task.
3. **Advanced Challenge (Optional)**:
   - When a task is added, its details (Task Name and Description) should be saved in localStorage.
   - On page load, fetch the stored tasks from localStorage and display them in the task list.
