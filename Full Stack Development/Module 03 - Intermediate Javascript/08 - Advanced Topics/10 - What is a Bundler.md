# What is a Bundler

### What is a Bundle ?

![](https://resources.metana.co/public/98/59/9859b15df5c54a6b8ad1654364473c691f8cd036c0d52c2c142effd90b15f1ce.png)

Imagine you have a big pile of LEGO bricks again , each representing a different part of your web application (HTML, CSS, JavaScript files). When you build a web application, it's more efficient to combine these pieces into fewer, larger chunks. Bundling in JavaScript/web applications is like creating bundles of LEGO pieces to make building faster and more efficient.

### So why do we Bundle ?

Bundling helps reduce the number of requests a web browser has to make to the server when loading a web page. Fewer requests mean faster loading times. Bundling also allows you to use the latest JavaScript features and libraries while ensuring compatibility with older browsers.
