# What is Transpiling and Polyfilling

### What is Transpiling?

![](https://resources.metana.co/public/ee/1e/ee1e207ed0d8087436831d5875b04311cb52793e62de1c8844bc041a18879a9e.png)

Transpiling is like translating a new language into an older one. In JavaScript, developers often use the latest and coolest features to write code. But here's the thing: not all web browsers understand this new code. They only speak an older version of JavaScript.

### Why Do We Transpile?

Transpilers help us make sure that our modern, fancy code can be understood by older browsers. It's like having a magical language converter. It takes the new code and turns it into something that every browser can understand. This way, our websites and apps work for everyone, no matter which browser they use.

### What is Polyfilling?

Think of polyfills as extra tools that fill in the gaps. Sometimes, there are new features or tricks in JavaScript that older browsers simply can't do. Polyfills are like adding special tools to make those older browsers behave like the newer ones.

### Why Do We Polyfill?

We use polyfills to make sure our code works even in older browsers that don't support the latest features. They add missing pieces to the puzzle. For example, if you want to use a cool new function that's not available in an old browser, you can use a polyfill to add that function so your code works everywhere
