# What is Tree-shaking

### What's Tree-Shaking

Imagine you have a big tree with lots of leaves. Some leaves are dead and don't serve any purpose. Tree-shaking is like shaking the tree to drop all the dead leaves, so you're left with only the healthy, useful ones.

### Why We Do Tree-Shaking

In the world of JavaScript, there are libraries and code that we might include in our projects, but we don't always use everything they offer. Tree-shaking helps remove the parts of these libraries that we don't need. This makes our web applications smaller and faster to load because they only contain what's essential.
