# Common Transpilers

### What's ESBuild

[YouTube video player](https://www.youtube.com/watch?v=Rs6ohJwS5-0)

ESBuild is like a super-fast, magic builder for your JavaScript code. It's a tool that takes your modern JavaScript code, which can be written in the latest and greatest features, and turns it into something that all web browsers can understand quickly.

### Why We Use ESBuild

Imagine you're in a race, and you want to build your web application as fast as possible. ESBuild is like having a rocket booster for your code. It's lightning-fast at turning your code into something that works in all browsers, making your website load super quickly.

### What's Babel

[YouTube video player](https://www.youtube.com/watch?v=aVLgL5LJh5Y)

Babel is like a language translator for your JavaScript code. It's a tool that helps you write code using the newest JavaScript features, even if some web browsers don't understand those features yet. Babel takes your fancy, modern code and turns it into older code that everyone can understand.

### Why We Use Babel

Think of Babel as a bridge between the past and the future of JavaScript. It allows you to write code using the latest and coolest features, making your code more readable and efficient. Then, Babel makes sure it works for everyone by translating it into older code versions.

In simple terms, ESBuild is a super-fast builder that optimizes your JavaScript code for speed, and Babel is a language translator that helps you write modern code while ensuring it works in older browsers. Both tools make your web development life easier and your websites better!
