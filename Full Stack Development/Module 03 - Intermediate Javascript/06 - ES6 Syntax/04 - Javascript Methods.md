# Javascript Methods

### What is Object.assign ?

`Object.assign()` is a method in JavaScript that is used to copy the values of all enumerable own properties from one or more source objects to a target object. It's like taking all the contents from a few backpacks (source objects) and putting them into one big backpack (target object). After the transfer, this big backpack (the target object) will have all the contents from the other backpacks.

### What are Array Methods ?

![](https://resources.metana.co/public/83/4f/834f69d0b6726766c8aa7d496b2ad469bc01f0c5734611bdf39e032ad731be45.png)

Imagine you have a basket of apples. Each apple has a number written on it, and you want to perform three different tasks with these apples.

### What is the Map Function

Let's say you have a list of apples with numbers [1, 2, 3], and you want to double each number and write it on the apples. The map function will take each apple, double the number on it (1 becomes 2, 2 becomes 4, 3 becomes 6), and give you a new basket with these colored apples.

### What is a Filter Function

The filter function is like choosing which apples to keep and which to throw away based on a condition. You have a basket of apples with numbers [1, 2, 3, 4, 5], and you only want to keep the apples with numbers greater than 3. The filter function will go through each apple, check the number, and keep only the ones with numbers greater than 3. So, you'll end up with a new basket that has only [4, 5] apples.

### What is a Reduce Function

The reduce function is like adding up all the numbers written on the apples until you have a single total. You have a basket of apples with numbers [1, 2, 3, 4, 5], and you want to find the total sum of all these numbers. The reduce function will start by adding the first two apples (1 + 2 = 3), then it will add this result to the next apple (3 + 3 = 6), and so on, until all apples are combined into one total sum, which is 15 in this case.
