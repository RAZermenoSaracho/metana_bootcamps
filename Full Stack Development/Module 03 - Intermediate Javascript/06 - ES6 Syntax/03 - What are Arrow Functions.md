# What are Arrow Functions

Imagine you're writing instructions for someone to do a task. In traditional JavaScript (before arrow functions), writing these instructions looked a bit formal and long. For example, if you wanted to tell someone to add two numbers, it would look like this:

![](https://resources.metana.co/public/41/8d/418d66dfec0c5716cd5d1fe5cdcd59602e9ae475f15a6553b64ca99ba0460e95.png)

Now, with arrow functions, introduced in ES6 (a newer version of JavaScript), **The Arrow `=>`**: This is where the name "arrow function" comes from. The arrow `=>` connects the parameters with what the function does. you can write these instructions in a shorter and more casual way. It's like using a shortcut. The same task of adding two numbers can be written as:

![](https://resources.metana.co/public/5b/0e/5b0edcae18b88aac74b6f8ea39cc463e74efdeb51024f8b717a05f2d7d094faa.png)
