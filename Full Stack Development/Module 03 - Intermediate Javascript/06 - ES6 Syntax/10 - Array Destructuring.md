# Array Destructuring

### What is a Spread Operator ?

Imagine you have two arrays, and you want to combine them into a new array. You can use the spread operator to achieve this easily. Here's an example:

### Let's look at an example

![](https://resources.metana.co/public/f6/bd/f6bd0e72d3ecaac6fa975402bf616966c109823e7b99087b34aab45cb8d7dfb7.png)

1. `arr1` contains the elements `[1, 2, 3]`.
2. `arr2` contains the elements `[4, 5, 6]`.

We want to create a new array `newArr` that contains all the elements from both `arr1` and `arr2`. To do this, we use the spread operator `...` to spread out the elements of both arrays within the square brackets `[...]`.

The resulting `newArr` will contain `[1, 2, 3, 4, 5, 6]`, which is the combination of all the elements from `arr1` and `arr2`.

### What is a Rest Operator ?

The rest operator (`...`) in array destructuring is a way to handle situations where you want to extract multiple elements from an array, but you're not sure how many elements there are or you want to handle the remaining elements in the array as a single entity.

Imagine you have a bunch of candies in a bag, but you don't know how many there are. You want to take some candies out of the bag and leave the rest for later. The rest operator helps you with this.
