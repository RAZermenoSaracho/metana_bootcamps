# Objects in Javascript

![](https://resources.metana.co/public/ee/98/ee98d408058d4127ad0f70a000f6f6798c1f48fc4f59fab9c6d5d33bd546ccb8.png)

In JavaScript, an object is a collection of related data and/or functionality. These usually consist of several variables and functions—which are called properties and methods when they are inside objects. Think of an object as a box that contains different things, like variables and functions, all grouped together in one place.
