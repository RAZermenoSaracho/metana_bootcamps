Imagine you have a big toy set with different kinds of toys - like cars, action figures, and buildings. Each of these toys is like an "object" in Object Oriented Programming (OOP). Just like your toys, each object in programming has its own special features and things it can do.

### Difference between a Class and a Object ?

### Objects are Like Toys

- **Objects Have Features:** Think about a toy car. It has features like color, size, and the number of wheels. In OOP, these features are called "properties." So, if you had a toy car in a computer program, its properties could be `color = red` and `wheels = 4`.
- **Objects Can Do Things:** Your toy car can roll, and maybe its doors can open and close. In OOP, we say that objects have "methods," which are like actions your toys can do. So in a program, a car object might have a method to `roll()` or `openDoor()`

### What is a Class ?

Imagine you have a blueprint for making a toy car. This blueprint is a "class" in programming. Every time you use this blueprint to make a car, you're creating a new object from that class. The class tells you what every car you make will have, like the number of wheels and the color.

### Understanding Constructors

Constructors are special functions in object-oriented programming that are used to create and initialize objects from a class. Think of a constructor as a recipe or a blueprint for creating objects. It defines what an object should look like and how it should be set up when it's first created.

[YouTube video player](https://www.youtube.com/watch?v=HboT8g_QSGc)

**Types of constructors ?** Types of constructor is differed from language to language. However, all the possible constructors are: • Default constructor • Parameterized constructor • Copy constructor • Static constructor • Private constructor

### Understanding Class Methods

Imagine you have a class called **`Dog`**. Inside the **`Dog`** class, you can have a method called **`bark()`**. The **`bark()`** method is a class method because it's something that dogs can do. When you create a **`Dog`** object, like **`myDog`**, you can call the **`bark()`** method on that object to make it bark.
