# Weekly Challenges 03 : Basics of Programming and JavaScript

In this module, we dive into the foundational concepts of programming, focusing on the versatile and widely-used language, JavaScript. You will learn core programming principles such as variables, data types, conditionals, and functions. By the end of it, you’ll be equipped with the basic tools to write and understand JavaScript code, enabling you to create interactive web pages and applications. Whether you’re a beginner or brushing up on your skills, this module will help you establish a strong foundation in JavaScript programming.

---

## Weekly Challenges

This will be a small challenge for you to do during the week. Weekly challenges are given as a way for you learn through trial and error. They are modeled in a way that makes you think on your own and how to tackle a problem with out step by step instructions on how to do it.

So, give one or more challenges from the bellow challenges as try and see how it goes!

**Challenge 1: Silly Sentence Maker**

Create a program that asks the user for a few random words, like a noun, verb, and adjective, and then generates a funny sentence using those words. Let the user’s creativity guide the outcome—perhaps you can create multiple sentence structures for different types of randomness. Have fun seeing what silly combinations you and others can come up with!

---

**Challenge 2: Magic Number Game**

Write a program that generates a random number between 1 and 10, and then asks the user to guess the number. Provide feedback to the user, such as “too high” or “too low,” and allow them to keep guessing until they get it right. Add your own fun rules, like limiting the number of attempts or giving a congratulatory message when they guess correctly.

---

**Challenge 3: Color Chooser**

Write a program that asks the user to input their favorite color, then changes the background color of the page based on their choice. Encourage the user to pick from a range of colors and experiment with how they can visually enhance their page. Get creative by suggesting themes like “mood colors” or “seasonal palettes.”
