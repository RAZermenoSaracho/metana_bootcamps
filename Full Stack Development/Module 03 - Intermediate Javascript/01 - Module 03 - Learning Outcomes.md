# Module 03 : Learning Outcomes

By the end of this module, students will be able to:

- Utilize advanced JavaScript concepts and ECMAScript features.
- Apply object-oriented programming principles in JavaScript.
- Leverage modern JavaScript syntax and ES6 features.
- Manipulate the Document Object Model (DOM) and manage browser storage.
- Implement asynchronous programming using async/await and promises.
- Use JavaScript to validate client-side forms and interact with web APIs.
- Understand and use modern JavaScript tools and techniques, including transpilers and bundlers.
- Gain a basic understanding of TypeScript and its advantages.

### Unit 11: More JavaScript

**Learning Outcomes**

- Deepen their understanding of core JavaScript concepts.
- Explain the importance and features of ECMAScript (ES).

### Unit 12: What is ECMAScript

**Learning Outcomes**

- What is ECMAScript.
- ECMAScript vs JavaScript.

### Unit 13: Object-Oriented Programming (OOP) in JavaScript

**Learning Outcomes**

- Understand the principles of object-oriented programming.
- Create and manipulate objects in JavaScript.

### Unit 14: ES6 Syntax

**Learning Outcomes**

- Write and use classes in JavaScript.
- Implement arrow functions for concise function expressions.
- Use various JavaScript methods effectively.
- Apply array destructuring to simplify code.

### Unit 15: Intermediate Level JavaScript

**Learning Outcomes**

- Explain the purpose and use of ES6 modules.
- Manipulate the DOM to dynamically update web pages.
- Use browser storage (local storage, cookies, cache) for persisting data.
- Implement client-side form validation using JavaScript.
- Understand and apply async/await for asynchronous programming.
- Use the Fetch API to make GET and POST requests.
- Implement exception handling to manage errors in JavaScript.

### Unit 16: Advanced Topics

**Learning Outcomes**

- Understand and use JavaScript promises in asynchronous functions.
- Explain the purpose and functionality of a bundler.
- Describe the processes of transpiling and polyfilling.
- Use Webpack for bundling JavaScript modules.
- Apply tree-shaking to remove unused code from final bundles.
- Identify and use common JavaScript transpilers.
- Gain a foundational understanding of TypeScript and its benefits.

### Assignment: Enhancing the Website with JavaScript

**Learning Outcomes**

- Add dynamic functionality to an HTML and CSS website using JavaScript.
- Implement form validations and handle user input errors.
- Fetch and display movie data from an external API.
- Manipulate the DOM to update the web page content dynamically.
- Create a movie slider to feature selected movies.
- Organize JavaScript files to maintain a clean project structure.
- Deploy the enhanced project on the Vercel platform.
