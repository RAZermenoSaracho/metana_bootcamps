# Handling Protected Routes in Express

***The process for handling protected routes in Express is identical to the process for the REST API.***

- If your Express backend is only a REST API, this step may already be completed.
- Use middlewares like `cookie-parser` and error logging to make it easier to create and debug your role-based authorization system.
- **Role-Based Authorization Suites**
  - There are also entire middleware suites and third-party services with APIs for setting up complex role-based authorization systems.
  - However, for most basic applications, these are overkill.
