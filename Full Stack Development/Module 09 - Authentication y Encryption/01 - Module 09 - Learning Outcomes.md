# Module 09 : Learning Outcomes

[YouTube video player](https://www.youtube.com/watch?v=2RoT87zaV3g)

By the end of this module, students will be able to:

- Understand the differences between authentication and authorization.
- Implement various authentication methods.
- Utilize different authorization frameworks, including RBAC, DAC, and ABAC.
- Securely store authentication data.
- Manage secrets using environment files and encryption techniques.
- Implement token-based authentication using JSON Web Tokens (JWT) and Passport.js.
- Understand and apply OAuth and OpenID in web applications.
- Implement secure methods of passing authentication data using cookies, local storage, and session storage.
- Protect routes and REST API endpoints using JWT and role-based security.
- Apply best practices for authentication and authorization in web applications.

### Unit 64: Understanding Authentication & Encryption

**Learning Outcomes**

- Distinguish between authentication and authorization.
- Explain various authentication methods.
- Describe different authorization frameworks including RBAC, DAC, and ABAC.
- Implement methods for storing authentication data securely.
- Manage secrets using environment files and encryption techniques.

### Unit 65: Authentication vs Authorization

**Learning Outcomes**

- Define and differentiate between authentication and authorization.
- Explain the importance of each in securing applications.

### Unit 66: Authentication Methods

**Learning Outcomes**

- Identify various authentication methods.
- Implement basic authentication techniques in applications.

### Unit 67: Authorization Frameworks

**Learning Outcomes**

- Describe Role-Based Access Control (RBAC), Discretionary Access Control (DAC), and Attribute-Based Access Control (ABAC).
- Apply these frameworks to secure applications.

### Unit 68: Storing Authentication Data

**Learning Outcomes**

- Implement best practices for storing authentication data securely.
- Use environment files for managing authentication data.

### Unit 69: Secrets Management

**Learning Outcomes**

- Explain the importance of secrets management.
- Implement secrets management using environment files and encryption techniques.

### Unit 70: Libraries for Authentication in Node Apps

**Learning Outcomes**

- Utilize JSON Web Tokens (JWT) for authentication.
- Implement Passport.js for authentication in Node applications.

### Unit 71: Token-based Authentication

**Learning Outcomes**

- Implement simple and complex token-based authentication mechanisms.
- Understand and use access tokens and refresh tokens.

### Unit 72: OAuth and OpenID

**Learning Outcomes**

- Explain the concepts of OAuth and OpenID.
- Implement OAuth in web applications.
- Describe the OAuth authentication flow.

### Unit 73: Methods of Passing Authentication Data

**Learning Outcomes**

- Implement secure methods of passing authentication data using cookies, local storage, and session storage.

### Unit 74: Working with Cookies

**Learning Outcomes**

- Use cookie parser middleware for handling cookies.
- Apply security flags for cookie security.

### Unit 75: Working with Local Storage

**Learning Outcomes**

- Implement local storage for storing authentication data securely.

### Unit 76: Working with Session Storage

**Learning Outcomes**

- Use session storage for managing user sessions.
- Explore advanced topics of session storage.

### Unit 77: Encrypting Secrets

**Learning Outcomes**

- Implement encryption techniques for securing secrets.
- Use bcryptjs for encrypting passwords.

### Unit 78: Protected Routes - Part 1

**Learning Outcomes**

- Implement protected routes using JSON Web Tokens (JWT).
- Secure routes based on user roles.
- Use middleware to check authentication status.

### Unit 79: Protected Routes - Part 2

**Learning Outcomes**

- Differentiate between frontend and backend protected routes.
- Protect REST API endpoints.
- Implement protected routes in Express and React.

### Unit 80: Best Practices for Authentication

**Learning Outcomes**

- Apply best practices for implementing authentication in web applications.

### Unit 81: Best Practices for Authorization

**Learning Outcomes**

- Apply best practices for implementing authorization in web applications.
