# Module 02 : Learning Outcomes

[YouTube video player](https://www.youtube.com/watch?v=1XK0qpbYshI)

By the end of this module, students will be able to:

- Develop well-structured web pages using HTML and CSS.
- Implement dynamic and interactive features using JavaScript.
- Create responsive web designs that work across various devices.
- Apply the principles of web design and development in creating a personal portfolio.
- Hosting a static website in Vercel.

### Unit 07: Introduction to HTML and CSS

**Learning Outcomes**

- Explain the roles of HTML and CSS in web development.
- Write HTML to create the structure of web pages.
- Use CSS to style web pages and enhance their appearance.
- Link CSS to HTML documents for styling purposes.
- Apply CSS layout techniques to design responsive and visually appealing web pages.

### Unit 08: Introduction to JavaScript

**Learning Outcomes**

- Develop JavaScript code locally to enhance web functionality.
- Define and use variables and constants in JavaScript.
- Identify and work with different data types in JavaScript.
- Create and manipulate arrays to manage collections of data.
- Implement control flows (if statements, loops) to manage the flow of a program.
- Define and invoke functions to perform specific tasks in JavaScript.
- Use interpolation to include expressions within strings.
- Understand and apply recursion for repetitive tasks.
- Add JavaScript to HTML pages to create interactive elements.
- Import JavaScript files into HTML documents to modularize code.

### Unit 09: Introduction to Responsive Design

**Learning Outcomes**

- Use CSS media queries to create responsive designs that adapt to different screen sizes.
- Utilize design tools such as Figma to plan and prototype responsive web layouts.

### Unit 10: Static Web Hosting on Vercel

**Learning Outcomes**

- Introduction to Vercel.
- Hosting a static website on Vercel.

### Assignment: Replicating a Website Using HTML and CSS

- Replicate a provided hosted website using HTML and CSS.
- Demonstrate the ability to structure a web page with HTML.
- Style the portfolio using CSS to create an appealing and professional design.
- Deploy the project on the Vercel platform.
