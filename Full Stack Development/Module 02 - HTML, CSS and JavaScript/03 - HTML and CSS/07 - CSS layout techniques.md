# CSS layout techniques

## **Flexbox**

[YouTube video player](https://www.youtube.com/watch?v=K74l26pE4YA)

- Flexbox is a one-dimensional layout model that allows for easy alignment and distribution of space along a row or column.
- **Usage:** Ideal for building responsive and flexible layouts, such as navigation bars or evenly distributing items in a container.

Now that we’ve covered the basics of CSS Flexboxes, it’s time to put your knowledge to the test! Practice and have fun with it here: [Flexbox Froggy](https://flexboxfroggy.com/).

## **Grid**

[YouTube video player](https://www.youtube.com/watch?v=uuOXPWCh-6o)

- CSS Grid is a two-dimensional layout system that allows for precise placement of elements in rows and columns.
- **Usage:** Useful for creating complex and responsive layouts, such as grid-based designs for entire web pages.

Now that you’re familiar with CSS Grids, it’s time to sharpen your skills! Try out some hands-on exercises here: <https://cssgridgarden.com/>

## **Float**

[YouTube video player](https://www.youtube.com/watch?v=xIJvkm-CgFQ)

- The `float` property allows elements to be taken out of the normal document flow and positioned to the left or right.
- **Usage:** Although less common in modern layouts, float were historically used for creating multi-column layouts.
