# What is HTML and Exercises

## What is HTML really ?

HTML stands for HyperText Markup Language, is like the foundation of all websites on the internet. Think of it as the skeleton of a website. It's not a programming language per se, but more like a markup language. This means it's used to structure and organize content on a web page, like text, images, links, and so on.

Why is it important to learn? Well, if you want to do anything related to web development or designing websites, HTML is your starting point. It's pretty much the most basic building block. Without HTML, websites wouldn't have any structure or content, which is, you know, pretty essential.

## And now what is CSS ?

[YouTube video player](https://www.youtube.com/watch?v=OEV8gMkCHXQ)

Alright, so CSS stands for Cascading Style Sheets. Think of it as the magic wand that makes websites look good. While HTML sets up the structure of a webpage, CSS comes in to handle the style. It's all about the design - colors, fonts, layouts, and even cool animations.

CSS lets you get creative with how web pages look. You can change how big the text is, the color of your buttons, the layout of your photos, pretty much anything that's about appearance. It's like the designer of the web world, deciding what styles go where.
