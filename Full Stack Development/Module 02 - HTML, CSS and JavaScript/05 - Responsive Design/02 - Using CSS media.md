# Using CSS media

As we mentioned in our earlier modules, CSS is the magic wand for websites! It helps make them look awesome on any device – whether it's a big computer or a tiny phone. With CSS, we can tell the website how to arrange things, like text and pictures, so they always fit and look great, no matter what size screen you're using
