# Understanding Arrays

### What are really Arrays ?

![](https://resources.metana.co/public/bf/70/bf7080b7c3969007e3bc432b3788a6d8ef5c37e89b91f2ee655e5cd319ac10cf.png)

Think of an array like a egg tray. Each egg in the tray is like an item in the array. The tray keeps the eggs in order, and each egg has its specific spot in the tray. If the tray is designed to hold 12 eggs, you can think of it as an array with 12 positions (or "indexes"), starting from 0 to 11.

### So what does an array look like ?

![](https://resources.metana.co/public/fc/8c/fc8c2ca4c28cd2e7bef693fd68762be9088fe47ce417a1de9a5483d7c9169269.png)

Arrays are a very useful tool in programming because they let you store and manage a set of items easily. You can go through the items one by one, pick out a specific item, or change the items as needed.

### What are Elements and Indexes ?

![](https://resources.metana.co/public/d0/51/d0516779554af07db68050ce3e3bcdaaf7f26e90126249dd99b6a8539a85398b.png)

**Elements**:

- **What Are They?** Elements are the actual items or values stored in an array. Think of them as the contents inside boxes.
- **Example**: Suppose you have an array of colors just like the code above : `["red", "blue", "green"]`. Here, "red", "blue", and "green" are the elements of the array.

**Indexes**:

- **What Are They?** Indexes (or indices) are the numbers that represent the positions of elements in an array. They are like the labels on the boxes that help you find which item is where. In most programming languages, including JavaScript, array indexes start at 0. So the first element is at index 0, the second at index 1, and so on.
- **Example**: Using the same array of colors `["red", "blue", "green"]`, "red" is at index 0, "blue" is at index 1, and "green" is at index 2.
