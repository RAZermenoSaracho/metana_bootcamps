# Importing JS files

### Imagine a LEGO Set

![](https://resources.metana.co/public/22/4b/224b098b41316138b2c27b2a7ab2dc40602df93f6b5108e449a115b6ebf0a487.png)

Think of building a website like assembling a LEGO set. Each LEGO block represents a different function or feature on your website - some blocks for text, others for images, and you even have special blocks for making things move or change color.

Now, imagine you have a magic bag filled with special LEGO blocks that can make your website do amazing things. This magic bag is like a JavaScript file that contains all the special code (instructions) to make your website interactive. The best thing about using a separate JS file is that you don't have to manually enter the instructions into the code all the time because you can use the src attribute to link an external JavaScript file to your HTML document

### But why src is important ?

![](https://resources.metana.co/public/db/5a/db5ac845c7b8802dcf52c071db8d6d9b0738ee03a03b08482c2d5429c3b68094.png)

Imagine you're building a house, and you have different workers specialized in different tasks. Each worker has their own set of tools and instructions. Now, you want to bring in a specific worker to handle the electrical wiring. How would you do that?

**You can give him Direct Instructions:**

- You could go to the electrical worker, give them all the instructions, and ask them to do their job. However, this would mean they have to stay with you throughout the construction.

**You can use a Blueprint (src):**

- Alternatively, you could give the electrical worker a blueprint (instructions) of the electrical work to be done. Then, you tell them, "Go to the house and follow these instructions." This way, the worker can come and go as needed, and you can focus on other aspects of construction.
