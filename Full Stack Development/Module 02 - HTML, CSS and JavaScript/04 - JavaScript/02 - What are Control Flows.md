# What are Control Flows

Imagine you're following a recipe to bake a cake. The steps you take, the order in which you do them, and the decisions you make along the way (like checking if you have all ingredients first) are similar to how control flow works in programming.

Control flow is the order in which individual statements, instructions, or function calls are executed or evaluated in a script. It's like a road map of code, guiding the computer on what to do next.
