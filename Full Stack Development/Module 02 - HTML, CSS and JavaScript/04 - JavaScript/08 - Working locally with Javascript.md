# Working locally with Javascript

Now it's time we install some extensions that will help you go through the next couple of modules. Here is a couple of different ways you can code in javascript locally. (Locally means in the current device that you are working on right now)

### 2. Using Live server (The traditional way)

[YouTube video player](https://www.youtube.com/watch?v=dkIvu2_0Svs)

### Here is a comparison between the two recommended extensions.

| Feature | Quokka JS | Live Server |
| --- | --- | --- |
| **Type of Extension** | Developer tool for real-time JavaScript code evaluation | Local development server for HTML, CSS, and JavaScript |
| **Installation** | Installed from the Extensions view in VS Code | Installed from the Extensions view in VS Code |
| **Activation** | Manually started for specific files or entire projects | Activated by right-clicking on HTML file and choosing "Open with Live Server" |
| **Real-time Feedback** | Provides real-time evaluation of JavaScript code | Automatically refreshes the web page as files are modified |
| **Live Comments** | Supports live comments using "//?" annotations | Not applicable |
| **Inline Values** | Displays inline values for variables in the editor | Hovering over a variable shows its current value |
| **Expression Evaluation** | Allows evaluation of complex expressions in the code | Not applicable |
| **Error Highlighting** | Highlights errors in real-time | Not applicable |
| **Interactive Playground** | Turns the code editor into an interactive playground | Not applicable |
| **Use Cases** | Debugging, learning JavaScript, prototyping, code reviews | Local development, prototyping, testing |
| **Auto-Refresh** | Not applicable | Automatically refreshes the browser as files are modified |
| **Port Configuration** | Not applicable | Supports configuring the server port |
| **Live Reload and Browser Support** | Not applicable | Supports live reload and works with most modern browsers |
| **Status Bar Information** | Provides information in the VS Code status bar | Displays server URL and status in the status bar |

**Note : You have the total flexibility to use which ever extensions you find more convenient!**
