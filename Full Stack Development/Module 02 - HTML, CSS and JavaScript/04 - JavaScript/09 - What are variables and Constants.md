# What are variables and Constants

### What do you mean by a Variable ?

In JavaScript, think of variables as containers or boxes that you can use to store information. Imagine you have a box labeled "score," and you can put different numbers in it whenever you want. So, a variable is like a named storage space for data that can change.

### Now what is a Constant ?

Now, constants are like superglued boxes. Once you put something in, you can't swap it out for something else. It stays constant. Like having a box labeled "PI" with the value 3.14 – it's not changing. So, a constant is a bit like a one-time-use, set-in-stone container.

So, in a nutshell, variables are like flexible storage boxes, and constants are like boxes that stay the same once you've put something inside. Easy peasy, right?

### How to assign a variable and Constants ?

So when it comes to creating variables and constants, there some specific keywords that you can use.

1. **Using `let`:**
   - `let` is used to declare a variable in JavaScript. You choose a name for your variable (like 'score' or 'name') and use the `=` to assign it a value. The key point with `let` is that you can reassign a new value to the variable later in your code.
2. **Using `const`:**
   - `const` is used to declare constants in JavaScript. Once a value is assigned to a constant, it cannot be reassigned or changed. This is useful for creating variables that should remain constant throughout the execution of a program. It's important to note that you can't reassign a value to a `const` once it's been set.
3. **Using `var`:**
   - `var` is an older way of declaring variables in JavaScript. Variables declared with `var` are function-scoped, and they can be redeclared within the same scope. However, it's generally recommended to use `let` and `const` for better code practices and scoping.
