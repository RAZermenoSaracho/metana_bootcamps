# Functions in Javascript

### What is a Function ?

![](https://resources.metana.co/public/af/75/af756036271fb1c2267799bbdc25960a420afad69fd9fdc4daebfcc684f58596.png)

Think of a function in JavaScript like a recipe in a cookbook. A recipe is a set of instructions to make a specific dish. In programming, a function is similar - it's a set of instructions that performs a specific task. Just like how you can use a recipe to make a dish whenever you want, you can use a function to perform a task whenever you need it in your code.

![](https://resources.metana.co/public/2c/b6/2cb67b56d64750350c10585b847495438d771bb6fbc00d7d5043ba73d465e5e8.png)

### **What makes a Function so special ?**

**Reusable Code**: Instead of writing the same code over and over again for the same task, you write it once inside a function and then call that function whenever you need to perform that task.

**Inputs (Parameters)**: Just like a recipe can have ingredients, functions can take inputs (known as parameters). These inputs are used by the function to perform its task.

**Output (Return Value)**: After doing its task, a function can give something back, called a return value. This is like the finished dish that comes out of following a recipe.
