# Understanding Data Types

![](https://resources.metana.co/public/15/3a/153a0622129e106c978df94e1d0eaa4c387cee30ec8ab8207d6bb81733d19800.png)

Alright, imagine coding is like building with LEGO bricks. Each piece has a specific shape and purpose, right? Well, in coding, we have something similar called “data types.” They’re like the building blocks of our code.

### Let’s understand the different Data Types

[YouTube video player](https://www.youtube.com/watch?v=808eYu9B9Yw)

**Number:** This type is used for any kind of number, be it an integer (like 1, 100) or a floating-point number (like 3.14, -0.5). JavaScript doesn’t differentiate between types of numbers

![](https://resources.metana.co/public/e7/71/e77170fca4afd48aa1321323fc474218907012220e8886633a6ef00be53ede27.png)

**String**: Strings are used for text. A string in JavaScript is a sequence of characters. It can be a single character like “a” or a whole sentence like “Hello, World!”. Strings are enclosed in quotes

![](https://resources.metana.co/public/86/25/8625ebf73743d45a4c1e4ba154e4865d4646a14d54a62e5ad7eae0a6ad273e53.png)

**Boolean**: This type has only two values: `true` and `false`. It is used to make decisions in your code, like checking if a condition is met.

![](https://resources.metana.co/public/e7/80/e780e390a839013e25f032d8422eb15a8a43b35c96205ff4e259ce2f4f857223.png)

**Undefined**: This type has only one value: `undefined`. It’s automatically assigned to variables that have been declared but not yet given a specific value.

![](https://resources.metana.co/public/fa/c7/fac777bfe410b1fd7af8ec2a39a161c5c5872509ce7cc79efd7640a63529b752.png)

**Null**: This type also has a single value: `null`. It’s used to represent “no value” or “nothing”. It’s similar to `undefined`, but it’s used more deliberately to indicate emptiness or the absence of a value.

![](https://resources.metana.co/public/dd/ad/ddadc329613457b20776003708d70ced0208f913385258ba660b2e1996226b5a.png)

**Object**: Objects are collections of related data and functionality. They are used to store various keyed collections and more complex entities. In JavaScript, almost everything is an object, including functions and arrays.

![](https://resources.metana.co/public/4d/72/4d723bcb14845258b7b8bcbc0ed85202ef79d11203e54415d9aea3536ac958a3.png)

**Symbol**: Introduced in the newer versions of JavaScript, a symbol is a unique and immutable primitive value and may be used as the key of an Object property.

![](https://resources.metana.co/public/56/1d/561d0c331728f77a5f470f0cd8d81e71a16dd19718b2ce37312701a983806657.png)
