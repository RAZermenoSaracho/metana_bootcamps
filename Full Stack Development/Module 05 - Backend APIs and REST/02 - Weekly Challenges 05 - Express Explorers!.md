# Weekly Challenges 05 : Express Explorers!

Welcome to this week’s **Weekly Challenges!** These challenges are designed to help you put your newfound skills into practice in a fun and creative way. Unlike assignments, these challenges are open-ended and give you the freedom to explore, create, and make something unique. While you can choose to tackle any or all of the challenges, we highly encourage you to **attempt at least one challenge within the week** to enhance your learning and discover the joy of building something from scratch. Let your imagination run wild!

---

### Challenge 1: **Meme Generator Madness**

**Description:**

Create a web application using Express.js and Handlebars that lets users generate their own memes. The user can input text for the top and bottom of an image, select from a few pre-loaded meme images, and see the result rendered dynamically.

- **Extensions:** Add more image options, allow custom image uploads, or create a random “funny caption” generator to spice things up.
- **Skills Covered:** Express routing, Handlebars templates, middleware for form data handling.

---

### Challenge 2: **Build-A-Beast Adventure**

**Description:**

Develop a REST API that allows users to create and manage their own fantasy creatures! Users can add, view, update, and delete creatures, defining attributes like “name,” “type” (e.g., dragon, unicorn, alien), “special abilities,” and “weaknesses.” Include an endpoint that generates a random creature with randomized attributes.

- **Extensions:** Use middleware to assign unique “power levels” to each creature, or implement a “battle” feature to compare power levels between creatures.
- **Skills Covered:** REST API creation, CRUD operations, middleware for dynamic data generation.

---

### Challenge 3: **Joke Generator & Collector**

**Description:**

Create an app that lets users generate a random joke from a predefined list or submit their own jokes to a MongoDB database. Users can also rate jokes (e.g., 1-5 stars) and view a leaderboard of the highest-rated jokes displayed dynamically using Handlebars templates.

- **Extensions:** Implement middleware to prevent duplicate joke submissions, add filtering for inappropriate words, or create a “joke duel” where users vote on competing jokes.
- **Skills Covered:** Express.js routing, CRUD operations with MongoDB, dynamic rendering using Handlebars, middleware for data validation and filtering.
