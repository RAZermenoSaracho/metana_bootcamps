# Issue Tracking with GitHub

Github Issue Tracking is a built-in feature of Github that allows teams to manage tasks, bugs, and enhancements directly within their code repositories. It provides a centralized platform for collaboration and communication among team members.

[YouTube video player](https://www.youtube.com/watch?v=6HWw7rhwvtY)

### **How to Create and Manage Issues in GitHub**

- Creating issues in GitHub is simple. Navigate to the "Issues" tab in your repository, click on "New issue," and fill in the details such as title, description, and labels. Once created, issues can be assigned to team members, tagged with labels, and prioritized using milestones.

### **Best Practices for GitHub Issue Tracking**

- Use descriptive titles and detailed descriptions to clearly communicate the issue or task.
- Utilize labels to categorize issues by type, priority, or status.
- Assign issues to specific team members to ensure accountability and ownership.
- Use milestones to group related issues and track progress towards specific goals or deadlines.
- Encourage collaboration by mentioning team members or referencing related pull requests and commits within issue comments.
- Regularly review and update issues to reflect the current status and progress of the project.
