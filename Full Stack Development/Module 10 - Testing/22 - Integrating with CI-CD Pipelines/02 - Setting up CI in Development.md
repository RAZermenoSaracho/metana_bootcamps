# Setting up CI in Development

- Configure Jest or your testing framework to watch for changes and run tests automatically on save.
- This ensures that errors are caught early during development.
- Refer to the Jest documentation for `-watch` and `-watchAll` options: <https://jestjs.io/docs/cli>
