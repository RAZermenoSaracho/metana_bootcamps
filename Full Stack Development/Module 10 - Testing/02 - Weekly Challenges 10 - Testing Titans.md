# Weekly Challenges 10 : Testing Titans

Welcome to **Weekly Challenges 10: Testing Titans!** This week, you’ll explore the fundamentals of software testing through hands-on challenges. Testing is critical for ensuring that your code works as expected, catches bugs early, and maintains high quality. These challenges are designed to give you a fun introduction to testing concepts and tools. Pick at least one to dive in and sharpen your testing skills!

---

### Challenge 1: **“Bug Hunter Game”**

**Description:**

Create a small JavaScript function (e.g., a function that adds two numbers, checks if a string is a palindrome, or finds the maximum number in an array). Write unit tests for your function using Jest to cover normal cases, edge cases, and possible errors. Introduce a bug into your code and modify your tests to catch it. Fix the bug and run your tests to verify everything works.

- **Extensions:** Add more complex edge cases to your tests or create a “leaderboard” to show which tests catch the most bugs.
- **Skills Covered:** Unit testing, writing and structuring tests, debugging, using Jest.

---

### Challenge 2: **“API Tester Game”**

**Description:**

Develop a simple REST API using Express that has endpoints for basic CRUD operations (e.g., adding, viewing, updating, and deleting items in a shopping list). Write API tests using a testing framework such as Jest with Supertest. Verify that each endpoint works correctly, and test for potential errors (e.g., trying to delete an item that doesn’t exist).

- **Extensions:** Add input validation to your API and write tests to ensure invalid inputs are handled appropriately.
- **Skills Covered:** API testing, using Jest with Supertest, testing for errors and edge cases.

---

### Challenge 3: **“Interactive Test Driven Counter”**

**Description:**

Create a simple React component that displays a counter with “increment” and “decrement” buttons. Write tests using Jest and React Testing Library to ensure the counter behaves as expected when the buttons are clicked. Start with writing the tests first (following Test-Driven Development principles), then build the component to pass the tests.

- **Extensions:** Add a “reset” button and write tests for it, or add conditions such as not allowing the counter to go below zero.
- **Skills Covered:** Test-Driven Development (TDD), React component testing, writing and running tests using Jest and React Testing Library.
