# Using LIMIT

The `LIMIT` clause in SQL is a simple yet powerful feature used to restrict the number of rows returned by a query. This can be useful for you to in situations where you only need a specific number of records from a larger dataset. For example, if you have a database of thousands of books but you only want to display the first 10 books based on alphabetical order, you can use the `LIMIT` clause to get this work done.
