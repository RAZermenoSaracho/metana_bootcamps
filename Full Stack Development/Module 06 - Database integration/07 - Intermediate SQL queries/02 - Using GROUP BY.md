# Using GROUP BY

### **What is GROUP BY ?**

The `GROUP BY` clause in SQL is used to arrange identical data into groups. This feature is particularly useful when you want to perform aggregate calculations on your data, such as counting, summing, or averaging, and then present these calculations grouped by one or more columns.

Imagine you have a table named `sales` that records sales transactions, including the columns `date`, `product_name`, and `amount`. If you wanted to know the total sales amount for each product, you could use the `GROUP BY` clause to group the rows that have the same value in the `product_name` column and then sum the `amount` for each group.
