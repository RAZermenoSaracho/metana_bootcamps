# Using COUNT, SUM, AVG

### **What is COUNT ?**

This function helps you find out how many rows (or entries) you have in your table that match a certain condition. For example, if you have a table of books, using `COUNT` can tell you how many books are in the table.

### **What is SUM ?**

This function adds up all the values in a specific column for rows that match a certain condition. If your books table includes prices for each book, `SUM` can calculate the total price of all books.

### **What is AVG ?**

Short for “average,” this function calculates the average value of a numeric column for rows that match a certain condition. If you wanted to find the average price of all books in your table, you would use `AVG`
