# Using ORDER BY

### **Why use ORDER BY ?**

The `ORDER BY` command in SQL is used to sort the results of a query based on one or more columns. You can use it to arrange the data in ascending order (which is the default) or descending order. For example, if you have a list of people with their ages, you can use `ORDER BY` to sort them from youngest to oldest or vice versa. It helps in organizing your data in a specific order to make it easier to understand or analyze.
