# Module 06 : Learning Outcomes

[YouTube video player](https://www.youtube.com/watch?v=6Es_o81Tx18)

By the end of this module, students will be able to:

- Understand the fundamental concepts of relational databases and normalization.
- Differentiate between SQL and NoSQL databases.
- Install and set up PostgreSQL for local development.
- Learn PostgreSQL data types and indexing.
- Create databases, tables, and schemas, defining primary keys, foreign keys, and constraints.
- Master basic SQL syntax and queries, including JOIN operations.
- Perform data insertion and updates.
- Manage databases by creating and running SQL seed files, and importing/exporting databases to SQL files.

### Unit 30: Intro to Databases

**Learning Outcomes**

- Understand what a Relational Database Management System (RDBMS) is.
- Learn about database hosts and ports.
- Grasp the basics of relational databases.
- Introduction to graph databases and key-value databases.

### Unit 31: PostgreSQL

**Learning Outcomes**

- Learn about the different data types in PostgreSQL.

### Unit 32: Basic SQL Queries

**Learning Outcomes**

- Understand and write basic SQL queries.

### Unit 33: Working with the psql Console

**Learning Outcomes**

- Gain proficiency in using the psql console to interact with PostgreSQL databases.

### Unit 34: Intermediate SQL Queries

**Learning Outcomes**

- Understand what JOINs are and how to use them.
- Learn to use ORDER BY in SQL queries.
- Use COUNT, SUM, and AVG functions in SQL.
- Implement LIMIT in SQL queries.
- Use GROUP BY in SQL queries.

### Unit 35: Migrations

**Learning Outcomes**

- Learn how to apply migrations using a SQL file.

### Unit 36: Maintenance & Security

**Learning Outcomes**

- Understand how to dump a database and schedule backups.

### Assignment: PostgreSQL Integration for Your Personal Portfolio

Set up a local PostgreSQL instance and integrate it into your personal portfolio application, replacing the existing MongoDB backend. You'll design a SQL database schema, create SQL files for initialization and seeding, and update your application to use PostgreSQL for data storage. This includes installing necessary libraries, writing SQL queries, and testing your implementation using Postman. Optionally, include Docker setup files for a containerized database environment.

**Assignment Outcomes**

- Gain hands-on experience in setting up and integrating PostgreSQL into a backend application.
- Develop proficiency in designing a SQL database schema and creating SQL files for database initialization and migration.
- Understand the process of replacing an existing NoSQL backend with a SQL backend.
- Learn to write and test SQL queries directly in the PostgreSQL console.
- Create and run SQL seed files to populate the database with initial data.
- Update backend code to interact with PostgreSQL, ensuring smooth data operations.
- Optionally, learn to use Docker for setting up and managing a containerized database environment.
