# What is RDBMS ?

**RDBMS** stands for **Relational Database Management System**. Imagine you have a collection of data like a bunch of spreadsheets. Now, an RDBMS is like a super organized version of those spreadsheets.

### How RDBMS works :

1. **Tables**: Instead of one big sheet, you have many smaller ones called tables. Each table holds information about something specific, like customers or products.
2. **Rows and Columns**: Just like in Excel, the tables have rows (horizontal) and columns (vertical). Each row is like a single entry or record, and each column is a different piece of information about that entry.
3. **Relationships**: This is where the "relational" part comes in. The tables can be connected or related to each other based on shared information. For example, a customer in one table might be related to orders in another table by a unique customer ID.
4. **SQL**: To talk to this super organized system, you use a special language called SQL (Structured Query Language). It's like giving commands to get the information you want, like asking for all the customers who bought a specific product.

So, an RDBMS is basically a really organized way to store and manage data using tables, rows, columns, and relationships, all accessed and manipulated using SQL. It's like having a neat and tidy filing system for your data!
