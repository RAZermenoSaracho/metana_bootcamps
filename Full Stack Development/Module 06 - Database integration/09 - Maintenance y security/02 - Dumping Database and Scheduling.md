# Dumping Database and Scheduling

In order to dump database into SQL file you need to use tools like pg\_dump. Scheduling is also crucial, as it automates the backup process. Regularly scheduled backups ensure that you always have recent backups, eliminating the need to remember to back up manually. For Scheduling can be done using Cron.

Cron is a time-based job scheduler in Unix-like operating systems. It allows users to schedule scripts or commands to run automatically at specified times, dates, or intervals. Cron is commonly used for automating system maintenance tasks, such as backups, updates, or cleaning up temporary files.
