# Weekly Challenges 06 : Database Daredevils

Welcome to **Weekly Challenges 06: Database Daredevils!** These challenges are designed to help you explore the world of relational databases, SQL, and PostgreSQL in a creative and hands-on way. Each challenge allows you to flex your database skills while having fun with unique and open-ended projects. We encourage you to **attempt at least one challenge within the week** to deepen your understanding of databases and enjoy the process of building something meaningful. Let’s get started!

---

### Challenge 1: **“Movie Night Database”**

**Description:**

Design and create a PostgreSQL database for a movie collection! Your database should include tables for movies, directors, and actors, with appropriate primary and foreign keys to connect them. Populate it with at least 10 movies, including data like title, genre, release year, director, and cast. Use SQL queries to find specific information, such as movies released in a particular decade or all movies directed by a certain person.

- **Extensions:** Create a “Top Rated Movies” query using a simple rating system, or write a JOIN query to find which actors have worked together most often.
- **Skills Covered:** Database creation, primary and foreign keys, basic and intermediate SQL queries, JOIN operations.

---

### Challenge 2: **“Restaurant Rave”**

**Description:**

Build a database for a restaurant’s menu and orders using PostgreSQL. Create tables for menu items, customers, and orders. Each order should be associated with a customer and contain multiple menu items, including their quantities. Populate the tables with sample data, then write SQL queries to get useful information, such as total sales per customer or the most popular menu item.

- **Extensions:** Use GROUP BY to group orders by date or customer and find the total revenue generated, or use ORDER BY to see the top-selling dishes.
- **Skills Covered:** SQL queries, data insertion and updates, GROUP BY and ORDER BY, relational database design.

---

### Challenge 3: **“Quiz Quest Database”**

**Description:**

Create a PostgreSQL database for a simple quiz game. Set up tables for questions, answers, and user scores. The questions table should include the question text, category, and difficulty level. The answers table should link to questions and indicate the correct answer(s). Create some example questions and use SQL queries to randomly select a set of questions for a “quiz round.”

- **Extensions:** Track user scores in a separate table and write queries to determine high scores or calculate the average score for all users.
- **Skills Covered:** SQL schema design, JOIN operations, using GROUP BY, and writing queries for data retrieval and aggregation.
