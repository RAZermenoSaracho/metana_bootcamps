# Data Types of PostgreSQL

A data type specifies what kind of data you want to store in the table field. While creating a table, for each column, you have to use a datatype. It identifies a particular type of data, like integer, Boolean, floating points, and so on. In this section, we are going to discuss the various basic data types and advanced data types used in PostgreSQL.
