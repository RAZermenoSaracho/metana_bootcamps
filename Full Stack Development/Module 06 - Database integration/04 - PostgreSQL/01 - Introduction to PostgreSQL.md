### **What is pgAdmin ?**

![](https://resources.metana.co/public/b8/59/b8599d85189670754a5d631ceb261368abe92da95a3377b9279052ca957bc1c9.png)

pgAdmin is an open-source administration and management tool for the PostgreSQL database management system. It provides a graphical user interface (GUI) that allows users to interact with PostgreSQL databases in a visual and intuitive manner.

\*\*Click the link to install: [https://www.pgadmin.org/\*\*](https://www.pgadmin.org/**)
