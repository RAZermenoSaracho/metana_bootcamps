# Basic SQL Queries

### **Why do we need to use SQL Queries ?**

Imagine you have a big library with lots of books. If you want to find a specific book, you wouldn’t search through every shelf randomly. Instead, you’d ask the librarian for help by providing specific details like the book’s title, author, or genre. SQL queries work similarly. They help you ask the database for specific information or perform actions like adding, updating, or deleting data.
