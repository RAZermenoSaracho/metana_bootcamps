# GitHub as a power tool

GitHub is the best way to show the evidence of the skills that you claim to have. But it’s important that you structure your Github in a concise manner so that it’s easier for the reader.

<https://www.youtube.com/watch?v=QDfLou004iE>

### **The GitHub Basics**

These are few steps that you can follow to improve your GitHub profile and give out professional impression to the recruiter.

1. Use the same Linkedin profile picture on your GitHub , this makes it easier for the recruiter to identify its you
2. Set up the GitHub Bio similar to your LinkedIn headline.
3. Include a link to your LinkedIn profile in your GitHub bio.

### **GitHub Pinned Repositories**

GitHub is a platform where you provide evidence to support the claims you make on your CV and LinkedIn profile.

The pinned repositories section of your GitHub should showcase the relevant programming languages you’ve mentioned on LinkedIn. For instance, if you’ve applied for a React developer position and your LinkedIn profile states that you’ve worked on projects using React, your GitHub should have your React repositories pinned to demonstrate the credibility of your claims to the recruiter.

### **GitHub Repository Description**

In your pinned repositories, ensure you write the purpose of the repository and the technologies you used. This will make it easier for the recruiter to check off all the required skills on their checklist.
