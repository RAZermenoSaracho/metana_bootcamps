# Metana Bootcamp Archive

> Personal backup repository for the Metana Bootcamp course materials.

## Overview

This repository exists exclusively as a long-term backup of the Metana Bootcamp content.

The goal is simple: preserve the course material in a structured, searchable, and offline-friendly format in case I need to revisit a topic in the future.

This repository is **not** an active software project.

There is:

- No source code to build
- No installation process
- No dependencies to install
- No application to run

Everything in this repository is stored as Markdown files organized by course, module, and lesson.

---

## Repository Structure

Each top-level directory represents a different Metana course.

---

## How to Navigate the Repository

### Option 1 (Recommended): Open `index.md`

Every course directory contains an `index.md` file.

The index acts as a table of contents and contains links to every module, lesson, assignment, and topic in the course.

Simply:

1. Open the course directory.
2. Open `index.md`.
3. Select the lesson you want to review.
4. Follow the links to navigate through the course.

---

### Option 2: Read `Course Description.md`

Each course also contains a `Course Description.md` file.

This file provides a high-level overview of the course, including its objectives, structure, and learning outcomes.

If you're not sure where to start, this is usually the best place.
