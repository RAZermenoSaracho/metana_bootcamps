# What is a smart contract

[Video: Smart contracts - Simply Explained](https://www.youtube.com/watch?v=ZE2HxTmxfrI)

Transcript for the AI

Smart contracts, also known as distributed applications, have become increasingly popular in recent years. The term was first coined by Nick Szabo in 1997, long before Bitcoin existed. Simply put, smart contracts are digital agreements stored on a blockchain, functioning as small computer programs that automatically enforce the terms of a contract without the need for intermediaries. For example, consider a crowdfunding platform like Kickstarter, where a third party holds funds and manages payouts based on whether funding goals are met.

A smart contract can replicate this process in a decentralized way: it holds the funds until a funding goal is reached, automatically transferring the money to the project creator if successful, or refunding supporters if the goal is unmet. Because these contracts are stored on a blockchain, they are immutable—meaning the code cannot be altered once deployed—and distributed, so all network participants validate the contract’s output. This makes tampering nearly impossible and removes the need for trust in a central party. Beyond crowdfunding, smart contracts have diverse applications including banking, insurance, and delivery payments.

While multiple blockchains support smart contracts, Ethereum is the most prominent platform built specifically for this purpose, using the Solidity programming language, which resembles JavaScript. Bitcoin also supports smart contracts but in a much more limited way. Understanding smart contracts helps clarify how blockchain technology is revolutionizing the way agreements and transactions are executed digitally
