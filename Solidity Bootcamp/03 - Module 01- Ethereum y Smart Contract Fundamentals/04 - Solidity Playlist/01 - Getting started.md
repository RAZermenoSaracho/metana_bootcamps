# Getting started

This section eases you into Solidity by writing and deploying your very first smart contract in Remix IDE. You'll build a simple counter to see how state updates work on-chain, learn how the constructor runs at deployment to initialise your contract, and understand what happens to variables you never explicitly set. By the end, you'll have a working mental model of the Solidity development loop.

### **Hello World**

Shows how to write and deploy a simple “Hello World” smart contract using Solidity (in Remix IDE), providing a beginner-friendly introduction to smart contract syntax.

<https://www.youtube.com/watch?v=g_t0Td4Kr6M>

### **Counter**

Walk through building a simple counter contract that can increment and decrement a number. This video is a basic Solidity application example, demonstrating state updates and function calls.

<https://www.youtube.com/watch?v=zzT3a7BJxgw>

### **Constructor**

Explains the constructor function in Solidity, which runs once at contract deployment. Demonstrates using a constructor to initialize state variables (like setting an owner) when the contract is deployed.

<https://www.youtube.com/watch?v=7XwWBr4TAz4>

### **Default Values**

Explains the default initialization of uninitialized variables in Solidity. Shows that unassigned variables have default values (e.g., 0 for numbers, false for Booleans) and discusses the implications for contract logic.

<https://www.youtube.com/watch?v=TPnu-uqJiVI>
