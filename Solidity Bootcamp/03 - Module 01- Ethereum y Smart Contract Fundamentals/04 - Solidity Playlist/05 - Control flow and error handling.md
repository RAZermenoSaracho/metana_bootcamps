# Control flow and error handling

This section covers how your contract makes decisions, repeats operations, and responds when something goes wrong. You'll write conditional logic with `if/else`, iterate with `for` and `while` loops (with an eye on gas costs), and handle failures safely using `require`, `revert`, and `assert`. The section closes with events — Solidity's built-in mechanism for emitting structured logs that off-chain applications and indexers can listen to.

### **If Else**

Demonstrates writing conditional logic in Solidity using if/else statements. Includes the syntax for conditions and an example of a ternary operator as a shorthand for simple conditional assignments.

<https://www.youtube.com/watch?v=Ld8bFWXLSfs>

### **For and While Loops**

Covers loop constructs in Solidity. Provides examples of **for loops** and **while loops**, how they can iterate over data, and cautions about writing loops in smart contracts due to gas limitations.

<https://www.youtube.com/watch?v=SB705OK3bUg>

### **Error**

Explains error handling in Solidity. Discusses the three ways to trigger errors – require, revert, and assert – and introduces **custom errors** (new in 0.8) to save gas and provide descriptive error information.

<https://www.youtube.com/watch?v=59MRDldSItU>

### **Event**

Introduces events in Solidity, which allow contracts to emit logs that external applications can monitor. Shows how to declare events and emit them (for example, logging when a value changes or a certain action occurs).

<https://www.youtube.com/watch?v=nopo9KwwRg4>
