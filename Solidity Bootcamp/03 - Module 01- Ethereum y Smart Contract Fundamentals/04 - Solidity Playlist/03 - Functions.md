# Functions

Functions are where your contract actually does things, and Solidity gives you a lot of control over how they behave. This section covers how to declare functions, control who can call them with visibility keywords, signal whether they read or modify state using `view` and `pure`, and return single or multiple values cleanly. You'll also learn how to write reusable function modifiers to enforce preconditions - like access control - without repeating the same checks in every function.

### **Introduction to Functions**

Demonstrates how to declare and use functions in Solidity, covering basic function syntax, parameters and return values, and the concept of function visibility.

<https://www.youtube.com/watch?v=Mm6834AAY00>

### **View and Pure Functions**

Describes read-only functions in Solidity. Explains the difference between **view** functions (which read state but don’t modify it) and **pure** functions (which neither read nor modify state), with examples of each.

<https://www.youtube.com/watch?v=vOmXqJ4Qzbc>

### **Function Outputs**

Shows how to return values from Solidity functions. Demonstrates functions with single and multiple return values, and how to assign return values to variables via tuple unpacking.

<https://www.youtube.com/watch?v=je7dWT6bEZM>

### **Function Modifier**

Illustrates how to create and use function modifiers in Solidity. Shows how modifiers can add pre- or post-conditions to functions (for example, restricting access to certain addresses) to avoid repetitive code.

<https://www.youtube.com/watch?v=b6FBWsz7VaI>

### **Visibility**

Covers the four visibility levels in Solidity for functions and state variables: **public**, **private**, **internal**, and **external**. Explains what each means and gives guidance on choosing the appropriate visibility for different scenarios.

<https://www.youtube.com/watch?v=f4sD6F-OhMY>
