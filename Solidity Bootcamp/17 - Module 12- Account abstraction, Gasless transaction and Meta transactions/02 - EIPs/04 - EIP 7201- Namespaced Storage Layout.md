# EIP 7201: Namespaced Storage Layout

This EIP explains a **namespaced storage layout** standard (ERC-7201) for Ethereum, allowing contracts to group state variables into *namespaces* and document their storage locations via `@custom:storage-location`.

[ERC-7201: Namespaced Storage Layout](https://eips.ethereum.org/EIPS/eip-7201)
