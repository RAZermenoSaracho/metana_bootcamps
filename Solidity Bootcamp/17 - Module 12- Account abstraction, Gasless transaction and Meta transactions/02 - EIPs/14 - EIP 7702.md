# EIP 7702

A deep dive into Ethereum’s EIP-7702, explaining how it lets users turn EOAs into smart contract wallets with a new setcode transaction, making account abstraction simpler, more compatible, and more gas-efficient.

[Video: EIP-7702: a technical deep dive by lightclient | Devcon SEA](https://www.youtube.com/watch?v=_k5fKlKBWV4)

Doc: <https://getfoundry.sh/reference/cheatcodes/sign-delegation>

### **EIP 7702 Vulnerability**

EIP-7702 enables Ethereum wallets (EOAs) to temporarily act as smart contracts for seamless one-click transactions, but introduces a critical security tradeoff where malicious delegated code could act as a backdoor to steal all tokens if not properly restricted.
