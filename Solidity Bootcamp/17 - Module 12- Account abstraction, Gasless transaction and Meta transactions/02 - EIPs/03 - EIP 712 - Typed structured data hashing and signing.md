# EIP 712 : Typed structured data hashing and signing

This EIP explains a **standard for hashing and signing typed structured data** in Ethereum (rather than raw bytes), introducing domain separation and a deterministic encoding scheme so that smart contracts can reliably verify off-chain signatures.

Doc: <https://eips.ethereum.org/EIPS/eip-712>
