# Gas Optimization

Provide 10 tips for gas optimization, including: minimizing on-chain data, using libraries, leveraging ERC-1167 for contract cloning, enabling the Solidity optimizer, using events, writing literal values instead of computed ones, avoiding unnecessary data copies (like arrays) by using storage pointers, avoiding for-loops over dynamic ranges, optimizing the order of variable declarations, and using tools like eth-gas-reporter.
