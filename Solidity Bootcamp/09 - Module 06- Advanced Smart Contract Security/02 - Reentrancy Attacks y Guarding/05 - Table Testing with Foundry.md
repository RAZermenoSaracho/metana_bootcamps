# Table Testing with Foundry

The Table Testing section from Foundry’s documentation explains that table testing is a data-driven approach where a test is executed multiple times with different predefined datasets. This allows developers to systematically cover a wide range of scenarios, improving test clarity and coverage. By separating test logic from test data, it becomes easier to maintain and extend tests for smart contracts.
