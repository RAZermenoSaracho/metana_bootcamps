# How does Ampleforth work?

Ampleforth is a decentralized protocol with a rebasing token, **AMPL**, that automatically expands or contracts its supply to stay near the value of a 2019 CPI-adjusted U.S. dollar. This rebasing happens across all wallets without changing ownership percentages, using oracles like Chainlink to guide daily adjustments.
