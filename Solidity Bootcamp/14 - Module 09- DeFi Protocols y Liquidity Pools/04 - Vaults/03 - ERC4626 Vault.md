# ERC4626 Vault

This video explains how to build a **tokenized vault (ERC-4626)** smart contract using OpenZeppelin. It covers how vaults issue shares for deposits, handle withdrawals, and how to extend them with fees or yield strategies like farming, lending, staking, or arbitrage.
