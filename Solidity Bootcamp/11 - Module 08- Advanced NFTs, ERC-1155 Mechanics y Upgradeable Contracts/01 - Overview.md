### Learning Objectives

- Understand the design and implementation of crafting systems, staking mechanisms, and dynamic NFTs in blockchain applications.

## Assignment

- **On-chain Game Economy:** An upgradeable ERC-1155 contract where players use a currency token to buy materials and burn those materials to craft unique items, with full access control, pausing, and security checks.
- **Upgradeable Design:** Starts with core buy-craft flow in V1, then adds new features in V2 (e.g., updated recipes, bulk actions) while preserving state through proxy upgrades and tested end-to-end.
