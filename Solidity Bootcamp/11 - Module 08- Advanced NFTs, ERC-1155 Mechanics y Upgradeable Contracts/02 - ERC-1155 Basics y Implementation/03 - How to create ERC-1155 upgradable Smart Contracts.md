# How to create ERC-1155 upgradable Smart Contracts

This tutorial demonstrates how to create and deploy an **upgradeable ERC-1155 smart contract** using OpenZeppelin’s proxy pattern. It walks through building a basic ERC-1155 contract, replacing standard libraries with upgradeable ones, initializing the contract properly, deploying with a proxy, and then upgrading the contract by adding new functionality.
