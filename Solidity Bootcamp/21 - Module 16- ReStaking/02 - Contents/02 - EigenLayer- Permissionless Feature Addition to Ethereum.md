# EigenLayer: Permissionless Feature Addition to Ethereum

This video covers EigenLayer, a set of Ethereum smart contracts that lets stakers extend cryptoeconomic security to new services by granting smart contracts the ability to enforce additional slashing conditions, enabling validation for systems like data availability, fair-ordering, bridges, and sidechains.
