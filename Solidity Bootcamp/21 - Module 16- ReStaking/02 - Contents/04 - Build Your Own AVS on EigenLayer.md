# Build Your Own AVS on EigenLayer

This video covers how to build a simple Actively Validated Service (AVS) on EigenLayer, including creating smart contracts, setting up a local test environment, writing TypeScript scripts, and implementing both user and operator functionality for on-chain content moderation.
