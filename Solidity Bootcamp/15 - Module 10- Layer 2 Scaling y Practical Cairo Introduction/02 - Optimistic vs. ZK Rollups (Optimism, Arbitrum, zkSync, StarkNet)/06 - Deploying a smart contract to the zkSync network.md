# Deploying a smart contract to the zkSync network

You can deploy smart contracts to the zkSync network using **Remix IDE** or **Foundry**.

🔗 Docs: [zkSync Quick Start Guide](https://docs.zksync.io/zksync-network/guides/quick-start/deploy-your-first-contract)

If you choose **Foundry**, please follow the official documentation: [zkSync Foundry Overview](https://docs.zksync.io/zksync-network/tooling/foundry/overview).
