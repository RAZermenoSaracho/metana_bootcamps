# Rollups

The video explains Ethereum rollups, a Layer‑2 solution that processes transactions off-chain while posting proofs to the mainnet, boosting speed and lowering fees without sacrificing security. It covers Optimistic Rollups, which use fraud proofs for validation, and ZK‑Rollups, which use cryptographic proofs for instant finality. Rollups allow Ethereum smart contracts to scale efficiently, making them a key part of Ethereum’s long-term strategy for high-performance blockchain applications.
