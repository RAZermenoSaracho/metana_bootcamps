# 📑 Assignment M14

This assignment focuses on exploring and completing the Echidna exercises, which are designed to help users analyze and test smart contracts for security vulnerabilities. The exercises were created by ***Trail of Bits***, and all credit for the content and structure of the exercises goes to them. The purpose of this work is to practice using Echidna to identify potential issues and understand secure smart contract development.

**Capstone Task:** Identify and resolve potential vulnerabilities in the capstone project.
