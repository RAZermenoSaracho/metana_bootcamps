# 🎯 Overview

## Module 14 – Static and Dynamic analysis

## Learning Objectives

- Learn to secure Solidity smart contracts using Slither (static analysis), Echidna (fuzzing & property testing), and Foundry (invariant & differential testing with multi-actor scenarios).
- Gain skills in designing, testing, and auditing DeFi/blockchain apps with static analysis, fuzzing, invariant checks, simulations, and off-chain data integration.
