# Differential Test

Shows how to perform differential testing (also known as metamorphic or cross testing) using Foundry. Likely demonstrates testing two implementations of a feature (for example, two different algorithms or an older vs newer contract version) with the same inputs to ensure they produce the same outputs. The video might set up two contracts and feed them identical transactions or calls in a test, then assert that their end states or outputs match, thereby catching any unintended differences.
