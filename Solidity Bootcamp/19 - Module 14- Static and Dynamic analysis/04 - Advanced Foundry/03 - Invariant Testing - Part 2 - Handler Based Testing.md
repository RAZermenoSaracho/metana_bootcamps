# Invariant Testing – Part 2 – Handler Based Testing

Continues with invariant testing by introducing handlers – specialized contracts that generate sequences of operations to test. The handler can randomize different actions (like calling different functions of the contract under test). This video shows how to set up a handler contract with functions that the fuzzer can call randomly, thereby simulating an unpredictable sequence of events on the contract and then checking invariants after those events
