# FFI | Testing with Foundry

Explains Foundry’s Foreign Function Interface (FFI) which allows calling external programs or scripts from within a test. Demonstrates how to use vm.ffi to run a script or command (for example, to fetch some data or run custom computations) during a test. This can integrate off-chain data or complex setup steps into your Solidity tests.
