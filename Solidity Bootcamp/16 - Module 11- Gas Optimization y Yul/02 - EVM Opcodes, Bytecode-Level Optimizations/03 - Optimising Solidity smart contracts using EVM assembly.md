# Optimising Solidity smart contracts using EVM assembly

This talk by Alex introduces **EVM assembly** by explaining what the EVM is and why understanding it matters. He describes the EVM as a **stack-based machine** with memory, storage, and gas costs for every operation, where most instructions consume and manipulate stack values. Assembly is presented as the middle layer between Solidity and raw bytecode, helping developers strengthen their mental model of how code actually executes on-chain.
