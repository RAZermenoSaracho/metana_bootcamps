# Assembly

This video introduces the Ethereum Virtual Machine (EVM) as a stack-based virtual machine with a small set of instructions categorized into stack, arithmetic, comparison, bitwise, memory, and contextual operations. It demonstrates how stack instructions like **PUSH, POP, SWAP, and DUP** work, using simple examples in the EVM playground to show how values are added, moved, and manipulated on the stack.
