# Introduction to Capstone Project

## Objective

The main purpose of a capstone project is to show that you can take an idea, design it, develop it, and present it as a finished product, much like you would in a real job. It also serves as a strong portfolio piece to demonstrate your abilities to others.

## 

## What We Expect

### Smart Contract:

Implement core logic using Solidity with best practices and audited libraries (OpenZeppelin, Solmate). Consider DeFi or governance features where relevant.

### Frontend (DApp):

Build an intuitive interface using React, Next.js, or Vue, and interact with the blockchain via **ethers.js** or **[viem.sh](http://viem.sh)**.

### Security:

Apply access control, re-entrancy protection, and pull-over-push payment patterns. Use Oracles for reliable price data and tools like **Slither** for analysis.

### Testing:

Include comprehensive testing — unit, end-to-end, fork, fuzz, and property-based (Echidna).

### Deployment:

- Deployment scripts : Develop deployment scripts keeping in mind whether it can benefit from multichain deployment
- Smart contract verification

### Documentation:

Include a project roadmap for post-bootcamp development.

- Add a [README.md](http://readme.md/) that provides steps to spin up project locally.
- Add Roadmap assuming you’ll be further developing this project after graduating from this bootcamp
