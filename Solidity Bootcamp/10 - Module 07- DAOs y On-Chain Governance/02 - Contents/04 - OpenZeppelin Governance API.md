# OpenZeppelin Governance API

This documentation covers the modular Governor contracts, providing customizable on-chain voting protocols similar to Compound’s Governor Alpha & Bravo. It explains how to set up a Governor using the Contracts Wizard or walkthrough guide, and details modules like GovernorVotes, GovernorVotesQuorumFraction, and GovernorVotesSuperQuorumFraction for defining voting power and quorum rules.

<https://docs.openzeppelin.com/contracts/5.x/api/governance>
