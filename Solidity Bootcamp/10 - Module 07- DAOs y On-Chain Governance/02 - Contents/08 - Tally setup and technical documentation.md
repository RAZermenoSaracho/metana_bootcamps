# Tally setup and technical documentation

Tally is built on top of the Governor standard. Tally indexes the on-chain data from and enables users to make calls to Governor smart contracts running autonomously on the blockchain.

To be compatible with the Tally app, we recommend you use OpenZeppelin’s Governor contract. This modular, battle-tested system of DAO smart contracts gives token holders control of their DAO on-chain.
