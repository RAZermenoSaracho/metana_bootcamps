# Assignment

#### Tokenizing Real-World Assets with Chainlink Oracles

Build a smart contract that represents a real-world asset on-chain (such as gold, real estate, or stocks), and use Chainlink Price Feeds to fetch the real-time price of that asset from the external world.

You are tasked with building a smart contract that does the following:

1. **Tokenizes a real-world asset** (e.g., gold, stock, or ETH) using an ERC20-like token.
2. **Fetches real-time asset prices** via Chainlink Price Feeds (e.g., XAU/USD, ETH/USD).
3. **Displays live prices** and allows minting tokens based on conditions (e.g., price thresholds or dynamic mint costs).
4. **Tracks price changes** over time with a `priceHistory` array and updates prices via Chainlink Automation or periodic checks.

**Capstone Task:** Implement oracles for the capstone project, if applicable.
