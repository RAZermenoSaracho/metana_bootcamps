# Chainlink – Price Oracle

The video shows how to get the ETH/USD price inside a smart contract using Chainlink’s price oracle. It explains importing the `AggregatorV3Interface`, setting up the price feed with the ETH/USD address, and using `latestRoundData()` to fetch and scale the price. A demo is run on a local fork to display the live ETH price, highlighting how Chainlink makes real-world data easily accessible to smart contracts.
