# Git and Github for Ethereum Developers

Welcome, aspiring Ethereum developers! Before diving deep into the world of Solidity and decentralized applications, it’s essential to be well-acquainted with the tools that will aid your development process. In this guide, we’ll introduce you to Git and GitHub, powerful tools to manage and collaborate on your codebase.

## What is Git?

Git is a distributed version control system that lets you track changes in a set of files. It allows multiple developers to work on the same project without interfering with each other’s work.

## What is GitHub?

GitHub is a platform that uses Git for version control. It lets you collaborate with others, manage projects, and keep track of issues and changes. GitHub provides a user-friendly interface to manage your Git repositories.
