# How to Create a Hardhat Project Step by Step

This tutorial walks you through setting up a Hardhat project from scratch, a crucial tool for developing, deploying, and testing smart contracts. Mastering Hardhat is essential for anyone aiming to become an advanced blockchain developer.

[Video: How to Create a Hardhat Project Step by Step!](https://www.youtube.com/watch?v=pKh_A0ecGgQ)

**Transcript for the AI**

Hello everyone, my name is Himer Sera from Dapp Dojo. In this tutorial, we are going to create our first Hardhat project. To do this, we’ll need to install a few essential tools, including Node.js, Visual Studio Code, and of course, Hardhat itself. We’ll start by setting up a new Hardhat project from scratch, install the OpenZeppelin libraries, compile our smart contracts, deploy them to the Sepolia test network, and finally verify the contracts. For more information about Hardhat, you can visit hardhat.org, where you’ll find tools, plugins, and comprehensive documentation. Although we’ll provide only the basics here, that site is an excellent resource for deeper learning. First, you need to install Node.js. Visit nodejs.org and download the version recommended for most users—this ensures compatibility with Hardhat and Solidity. Visual Studio Code is also recommended for writing and managing your code; download it from code.visualstudio.com. Once installed, verify Node.js and npm (which is bundled with Node.js) by typing node -v and npm -v in your terminal. Next, create a new folder for your project (e.g., my-project), navigate into it, and initialize a Node.js project using npm init -y, which generates the package.json file. To install Hardhat, run npm install –save-dev hardhat, then initialize the Hardhat project with npx hardhat init, selecting the JavaScript option, agreeing to create a .gitignore file, and allowing installation of the sample project dependencies. Your project structure will now include folders like contracts, scripts, test, and files like hardhat.config.js and package.json.

To compile your contract and ensure everything is working, run npx hardhat compile. If successful, you’ll see a new artifacts folder containing your compiled contract’s ABI and bytecode. You can run tests using npx hardhat test, and to test specific files, use npx hardhat test path/to/file.js. If you need to clear and regenerate artifacts, run npx hardhat clean followed by npx hardhat compile. To expand your contract’s functionality, install the OpenZeppelin library using npm install @openzeppelin/contracts. For upgradeable contracts, install @openzeppelin/contracts-upgradeable as well. These will appear in your node\_modules folder and include commonly used templates like ERC20.sol. Open your hardhat.config.js file and ensure you specify the Solidity version (e.g., 0.8.19). To manage sensitive data such as private keys and API keys, install the dotenv library using npm install dotenv, then create a .env file in your root directory. This file should contain variables such as SEPOLIA\_URL, PRIVATE\_KEY, and ETHERSCAN\_API\_KEY. Be sure to list .env in your .gitignore to prevent accidentally exposing your credentials.

To obtain your Sepolia RPC URL, visit Alchemy, create a free account, and set up a new Ethereum app using the Sepolia network. Copy your API key and paste it into your .env file under SEPOLIA\_URL. For your private key, use a test-only MetaMask account with no real funds, and copy its private key to PRIVATE\_KEY. Then update your hardhat.config.js to import dotenv and use process.env to pull these variables into a new sepolia network object under the networks configuration. For example, specify the url as process.env.SEPOLIA\_URL and accounts as [process.env.PRIVATE\_KEY], ensuring fallback values if any are undefined. You can also run a local Hardhat node using npx hardhat node, which provides temporary accounts for local testing. To deploy a contract, create a script under the scripts folder (e.g., deploy.js) and run it using npx hardhat run scripts/deploy.js –network localhost. To deploy to Sepolia, change the network to sepolia in the command. If you find yourself repeatedly typing deployment commands, you can simplify your workflow by adding custom scripts in your package.json file under the scripts section (e.g., deploy:localhost, deploy:sepolia).

To verify your deployed contract on Etherscan, first obtain an Etherscan API key from etherscan.io, log in, and navigate to the API section to create a new key. Add this to your .env file as ETHERSCAN\_API\_KEY, and then configure hardhat.config.js to include the etherscan object with your API key. To verify your contract, run npx hardhat verify –network sepolia . Make sure to specify any constructor parameters such as unlockTime if your contract requires them. Once verified, your contract on Etherscan will display a green check mark and allow you to interact with it directly—viewing variables and calling functions like withdraw() or owner().

Congratulations! You’ve now successfully set up and configured your first Hardhat project, deployed a contract, run tests, added OpenZeppelin libraries, and verified your contract on the Sepolia testnet. Thank you, and have fun building on Ethereum!
