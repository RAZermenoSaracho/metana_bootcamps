# What is an AMM and why do we need it?

Explain Automated Market Makers (AMMs) use a formula (`x * y = k`) to set prices based on supply and demand. As one asset is traded, its price changes to keep the pool balanced. Liquidity providers earn fees by adding tokens to the pool.

[Video: What is an Automated Market Maker? (Liquidity Pool Algorithm)](https://www.youtube.com/watch?v=1PbZMudPP5E)

The video explains AMMs as smart contracts that replace traditional order books by using a simple formula (x \* y = k) to set prices. Traders buy/sell directly with the contract, and arbitrage keeps prices fair. Liquidity providers earn fees by supplying token pairs. It’s a more efficient model for blockchains.
