# Uniswap V2 – Swap Tokens

Explain how to perform token swaps using Uniswap V2, how the **swapExactTokensForTokens** function works with intermediary tokens like WETH, and provide a brief overview of simulating trades on mainnet using Ganache.

> **Note:** Ganache is no longer in use. Please use **Foundry** or **Hardhat** for your development and testing instead.
