# Uniswap V2 – Optimal One-sided Supply

Explains how to calculate the exact amount of one token to swap when adding liquidity to Uniswap, ensuring both tokens are fully used. It uses reserve ratios, includes a formula for the optimal swap, and implements it in a Solidity function.
