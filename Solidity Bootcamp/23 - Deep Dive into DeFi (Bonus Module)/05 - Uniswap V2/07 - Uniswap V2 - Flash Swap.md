# Uniswap V2 – Flash Swap

Explains how to perform a flash loan on Uniswap using Solidity. It walks through writing a smart contract that borrows tokens, uses them within the same transaction, and repays them with a small fee (0.3%). The contract ensures security by validating the Uniswap pair contract, decodes the loan data, and transfers the borrowed amount plus fee back to complete the loan, all in a single function call.
