# Learn how to use Viem

This tutorial covers working with Viem, including: interacting with accounts and clients, writing account scripts, creating clients, loading accounts with Ether, interacting with smart contracts, writing contract scripts, and handling events, including both reading and writing them through dedicated event scripts.
